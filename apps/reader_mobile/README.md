# reader_mobile

Spectacular Reader 的 Flutter 应用宿主，包含 Android、iOS、macOS 和 Windows 工程。项目仍在开发，当前专项验收主要覆盖 Android 真机；平台目录存在不代表已完成同等验收。

## 当前功能与职责

- `lib/main.dart` 初始化日志、当前数据库、书库和进度存储，进入书架、统计、书评、我的四页应用壳。
- `lib/library/` 负责 EPUB 文件导入、去重、内容摘要、修订替换、分组、标签和书籍生命周期。文件统一保存在 `books/<id>`，原 EPUB 不改写。
- `lib/reader/epub_reader_page.dart` 通过核心 `EpubFormatOpener` 打开书籍，将进度、标注、装饰、偏好、用户字体和背景交给 `ReaderPage`；EPUB 解析、章节准备和排版实现位于 `reader_core`。
- `lib/storage/` 只维护完整 V1。新库一次建齐全部表和索引；已知的早期 V1 只补建编辑草稿与保留版本两表，结构已完整的开发 V2 只将版本号归一为 1。两者均使用原 `reader.sqlite`，不复制或清空数据。未知版本或结构不符时保留原库，进入临时模式，不清理书籍文件。
- `lib/search/scan_search_service.dart` 逐章扫描原文，返回上下文和 CFI；当前阅读搜索未使用 2-gram 索引。
- `lib/reader/reading_session_tracker.dart` 记录前台阅读时段，`lib/home/stats_page.dart` 汇总统计；`lib/diagnostics/` 提供运行事件与日志导出。

内容修订是当前业务功能：替换书籍时按原文证据重新关联进度和标注，保留书评与阅读记录；写入前校验内容摘要，拒绝过期会话覆盖。数据库打不开时应用可退回内存模式，该模式不提供持久化能力。

当前支持 EPUB。TXT、PDF 只有核心格式契约；TTS 依赖已声明、UI 有可选回调，但应用尚未接入朗读流程。全局实现状态见 [根 README](../../README.md)。

统计中的阅读次数是连续前台片段次数；退出、后台和再次进入会产生不同片段。跨自然日的翻页和字数按时长分配，标为估算且总数守恒；日均以实际阅读天数计算，字速不是净阅读速度测量。到达正文末页不会自动标记读完；正式数据库将同时提交的读完标记与书评放在同一事务中，失败一并回滚。仅标记读完不改已有书评；取消读完后，已有书评仍可查看、复制，再次标记读完后才能编辑。

## 文字装饰

阅读选区的“装饰”支持字体、背景色、本地图片、边框和九种高亮样式；新建装饰默认显示高亮，可直接点击效果样本与快捷颜色。编辑器固定显示实时预览与保存按钮，高亮圆角与跨行连块共用正文绘制。自动装饰规则支持本书／全局作用域、分组排序、Unicode 正则和大小写选择；可插入数字、引号内文字、英文单词等常用表达式。当前章预览默认展示前 5 条，可展开到前 50 条；调节外观立即更新已有结果，修改匹配内容才清空结果。正则按正文文本块匹配，不跨段；格式错误会提示，超过 1 秒的规则在当前会话暂停，不阻塞其他规则。

手工装饰和自动规则共用图片预览与绘制，图片支持裁剪铺满、完整显示、拉伸铺满、平铺和点九拉伸。导入普通图片后点击“转为点九背景”，拖动内容区及四角，也可用滑杆与加减按钮调整四边的源图像素边距，并预览短句与多行文字。采用 Reeden 的行内气泡方式：内容区高度对应文字高度，边角等比缩放，中间随文字长度拉伸；内容区、拉伸区和缩放参数随装饰保存。应用把转换结果保存为独立的 `.9.png` 副本，原外部文件和仍被其他记录引用的图片保留。导入未编译的 `.9.png` 时识别四边单个连续标记区，保存时保留单像素标记，绘制前去除标记边；多段拉伸标记和已编译的 Android NinePatch 数据暂不解析。

每行命中区间独立铺放；同一图片被其他规则切分时共用原命中图案，不重复边角。横排点九按内容边距预留两侧空间，并用完整图案高度撑开命中行，邻字随段落重新断行，不被背景覆盖；换行后的片段各自保留两侧边角，页首尾也保留图案空间。图片透明度可调，普通图片还可调整裁切圆角；点九图片保留素材自身边角。图片失效时保留背景色，只有全库手工装饰和规则均不再引用时才清理。转换保留原图片透明度，JPEG 中的黑底不会自动变透明，透明素材需使用 PNG 或 WebP。普通图片、颜色和线条变化不改变正文度量；点九边距变化允许重排，但不改写 EPUB、原文 CFI 或标注内容，规则命中不生成标注记录。

点九的拉伸区与内容边距独立，边距按源图像素和当前缩放换算，不随中间拉伸而加宽。解码图片后先将边距交给正式布局，再绘制背景；仅改颜色与透明度仍复用几何，移除点九恢复原排版，重排后按原 CFI 续读。预览不再限制图案上下留白为 16 dp。竖排与 RTL 保留原有绘制方式，本次重排修复针对横排正文。声明式组件树、首行测量与四角坐标保留完整布局参数，避免拆散接缝导致参数失配；这类长度与参数数量例外的裁切、重排风险由像素、跨行跨页、CFI、缓存和窄屏回归约束。

样式规格参考 Reeden [230 号报告 §6、§9](../../参考/reeden/reports/230-highlight.md)、[520 号报告 §4](../../参考/reeden/reports/520-spec-render.md)、本地 `work/blutter-out/pp.txt` 中的点九气泡文案、[Android 点九图说明](https://developer.android.com/studio/write/draw9patch)及 [NinePatchDrawable 边距实现](https://android.googlesource.com/platform/frameworks/base/+/refs/heads/main/graphics/java/android/graphics/drawable/NinePatchDrawable.java)。本项目沿用自己的 CFI、规则逐属性覆盖和图片存储，不复用其逆向实现。Reeden 的整段块级卡片模式、主题绑定及背景冲突策略不在本次实现范围。

## EPUB 编辑

EPUB 编辑仅在桌面端提供，Android 和 iOS 阅读菜单与选区菜单均不显示编辑入口。当前已完成 macOS 编辑链路验收，Windows 暂缓验收。桌面阅读菜单或选区菜单进入工作副本，工作区参考 Sigil 的资源分类、源码标签和独立预览布局；文件、编辑、工具和视图菜单提供保存、导出、查找替换、元数据、目录、章节顺序与分合章入口。源码与预览支持精确双向定位，检查器显示元素、祖先、同名类生效值和作者声明来源。

- 首页宽窗使用侧栏导航，书架按可用宽度增加列数；窄窗保留底栏。macOS 初始内容窗口为 1200 × 760，macOS 与 Windows 自动保存并恢复窗口大小和位置，Windows 同时保留最大化状态。
- 桌面正文分页模式支持滚轮向下翻下一页、向上翻上一页，密集事件以 250 ms 间隔节流，翻页未完成时不追加滚轮请求；连续滚动模式沿用正文滚动，阅读菜单、选区和编辑预览不触发滚轮翻页。
- 桌面正文支持方向键、Page Up／Page Down、空格／Shift + 空格前后翻页，左右方向跟随 RTL 阅读方向；连续滚动模式使用相同按键上下翻屏。翻页准备期间不堆积按键请求，输入框、选区、面板与编辑预览不会误翻正文。
- macOS 使用 `⌘ + F` 搜索正文或书架，Windows 使用 `Ctrl + F`；已选正文可用 `⌘ / Ctrl + C` 复制。`Esc` 逐层关闭面板，正文中按 `Esc` 或右键打开阅读菜单，`F1` 或菜单顶部的信息按钮查看操作说明。
- 书架网格和列表均支持右键菜单，可阅读、查看详情、进入多选、新建分组、更新 EPUB 或确认删除；`⌘ / Ctrl + O` 导入 EPUB，文件选择器打开期间不重复弹出。`Esc` 退出书架搜索或多选，切换首页页面后隐藏书架不接收快捷键。
- 编辑窗口从 720 逻辑像素起并排展示源码和预览，从 1000 起停靠书籍浏览器；较窄窗口通过抽屉或标签访问文件。分栏可拖动，浏览器和检查器可收起，窗口缩放保留源码缓冲、换行状态及预览位置。
- 浏览器按正文、样式、图片、字体和其他资源分类，正文遵循书籍阅读顺序；可用文件名或真实路径筛选，同名文件显示路径提示。打开正文或切换标签同步预览章节，打开 CSS 等资源保留正在对照的章节。
- 源码提供语法高亮、折叠、自动换行、光标行列和文档内查找替换；每个文档保留自己的查找输入。
- 手机预览使用正式阅读引擎，屏幕固定为 360 × 800 逻辑像素、3 倍屏幕倍率，对应 1080:2400 比例；圆角屏幕、听筒、前置镜头和底部指示条构成手机外壳。窗口缩放只等比缩放整机，不改变分页尺寸。预览支持左右滑动及上一页／下一页按钮，不使用滚动翻页；可切换书籍样式和当前阅读设置，预览进度只写内存。

- 同名 class 写入共享 CSS。先展示全书影响范围；高优先级声明冲突时可保留作者优先级或显式统一该属性。归属清单只用于恢复，实际渲染仍来自标准 XHTML/CSS。
- 保存更新书库副本，保留书籍身份、进度、批注和书签。正文变化按内容证据迁移位置；无法确认的位置保留为待重新定位。
- 自动草稿保留未完成的源码；语法错误允许留在草稿，不能提交。过期草稿可以导出保留，但不能覆盖较新版本。
- 保留首次编辑前原版和最近一次保存前版本；恢复书籍内容不会恢复旧数据库或丢弃之后新增的笔记。原始外部 EPUB 不自动覆盖，另用“导出 EPUB”选择输出位置。
- 编辑撤销历史最多 100 项、旧资源 32 MiB，超出后释放最早历史；图片和字体按条目读取，输入期间不重新打包整本 EPUB。
- 预览按正文、CSS 导入、图片和字体等资源依赖失效，未受影响的章节复用准备结果；章节结构最多缓存 3 章，完成布局仍遵循 64 MiB 缓存上限。

相关实现位于 `lib/editing/`、`reader_core/lib/editing/`。Windows 验收入口是 `.github/workflows/epub-editor-windows.yml`，只有实际运行通过才计为平台验收，工程目录本身不代表兼容性保证。

### 本地 EPUB 工具

从“工具 → 本地 EPUB 工具”进入，处理逻辑迁自 [wangyyyqw/epub-toolkit](https://github.com/wangyyyqw/epub-toolkit)，保留当前编辑框架，不引入其书库或联网功能。只提供 EPUB 编辑工具，不包含 TXT 导入、转换或导出。

- 转换：EPUB 2／3、OpenCC 简繁转换。
- 结构：体检与选择性修复、目录／地标／页码导航、结构重排、合并与分册、资源名称混淆与还原。
- 图片与字体：图片压缩、WebP 双向转换、隐形水印、字体扫描与 HarfBuzz 子集化、定向字体加密。
- 注释与正文：正则命中预览和清理、批注提取、脚注与弹窗互转、阅微／得到／掌阅注释转换、拼音标注。

操作先提交当前有效源码到工作副本，再在后台处理临时 EPUB；结果通过资源和引用校验后一次应用，可一步撤销。非法源码或处理失败不覆盖工作副本；分册单独导出，不覆盖同名文件。体检属于本地结构检查，不是 EPUBCheck 完整规范认证。跨文件脚注暂不转换，拼音多音字需人工校对；字体加密改变正文码点，界面明确警告其对复制、搜索和朗读的影响。

macOS 的 HarfBuzz 随原生资产自动构建。WebP 组件使用本机已准备的 `cwebp`，在应用构建后复制进包内；不在构建时自动安装 Homebrew 或下载组件：

```bash
# 在应用目录执行
flutter build macos --release --no-pub
bash ../../packages/epub_toolkit/tool/bundle_cwebp_macos.sh \
  "$PWD/build/macos/Build/Products/Release/reader_mobile.app"
```

工具回归位于 `packages/epub_toolkit/test/`，编辑桥接回归位于 `test/editing/book_editor_toolkit_test.dart`。macOS 实窗验收入口为 `integration_test/epub_editor_local_tools_desktop_test.dart`，使用临时 EPUB 和内存数据库，不修改已有书库；同时验证手机分页、包内 WebP、真实字体子集以及保存／导出重开。Windows 原生工具构建仍需对应平台验收。

本次 macOS 实测为 Apple Silicon。当前包内 `cwebp` 及其动态库仅为 `arm64`，Intel Mac 需准备匹配组件并另行验收；应用主程序为通用二进制不代表所有工具组件也具备双架构支持。

大书编辑基准复用上述本地生成的 144 MiB、48 图、单 HTML 200 页样本，在核心包执行：

```bash
flutter test --no-pub test/editing/epub_edit_stress_test.dart \
  --dart-define=RUN_EDITOR_STRESS=true
```

报告写入 `apps/reader_mobile/dist/epub-editor-stress.json`；本地测试进程的事件循环间隔和 RSS 不代表 Android Release 帧率。
