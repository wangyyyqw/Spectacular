从仓库根目录运行，先将 Flutter、Python 和 Git Bash 加入 PATH：

```powershell
python tool/build_local.py
python tool/build_local.py --platform arm64
python tool/build_local.py --platform winx64
```

默认复用本地依赖缓存，Flutter 使用 `--no-pub`，Android Gradle 使用 `--offline`。只有缓存缺失时添加 `--allow-downloads`。

每轮本地构建将 `apps/reader_mobile/pubspec.yaml` 中的内部版本号加一，正式版本号仅在明确要求发新版时修改。两个平台一起构建时共用编号，单独启动构建则分配下一编号。失败的构建保留已分配编号，重试不会复用。

交付文件保存到被 Git 忽略的 `apps/reader_mobile/dist/`：

- `阅微 Extend arm64 v1.0.0（2）.apk`
- `阅微 Extend winx64 v1.0.0（2）.zip`

单独运行 `tool/build_apk.sh` 也会自动递增编号。APK 的固定文件名副本供现有 CI 与上传脚本使用。直接运行 `flutter build` 会绕过编号分配，因此本地交付请使用上述入口。
