# 界面改造与真机验收（2026-11-04）

## 结论与范围

在[项目审计修复](审计报告-2026-11-04.md)完成后，统一改造书架、统计、书评、个人页、书籍详情与阅读控件。应用采用纸白背景、墨黑主色、文字分组与平面底栏，普通控件圆角 4，弹层顶部圆角 8，移除 MD3 种子配色、大圆角与装饰渐变。书籍原封面、评分金色及标注颜色保留各自含义。

未新增依赖，也未改变数据库结构、书库格式或阅读正文排版。自动验收仅运行本次新增的 `test/audit/`，累计 50 项通过；另外有 8 个工程探针通过。Android debug 离线构建成功，保留数据安装到 MEIZU 20，并完成以下真机观察。微信界面观察仍等待 Android Use 所要求的用户额外确认，因此完整目标尚有这一项未完成。

验收中追加修复：直接标记读完但没有 `lastReadAt` 的书，书架现在优先显示“已读完”；列表布局避免 Material 2 `ListTile` 压缩封面高度；三列字幕把阅读状态置于作者之前；真机长时长不再被省略号截断；图书详情辅助文本使用次级正文色提高对比度。

主题配置拆为小型配置和映射函数；少量 Widget 构建函数超过 40 行，保留同一控件的线性树以便检查约束和回调，不把简单布局拆成仅调用一次的碎片。既有大型页面未做无关重构，后续布局变动仍需窄屏验证。

## 未处理风险与下一步

- 微信观察受工具确认限制；设备的音乐入口只代表所观察的 Flyme 集成版本。下一步是获得确认后补看微信可见界面，若发现影响本项目的布局问题再修正。
- 本轮只验证一台竖屏手机，软键盘、大字号、横屏、其他系统和长期性能仍需专项检查。长数值使用缩放保持完整，极大系统字号下字号可能缩小；书架长书名/作者保留省略，可从详情看完整文本。
- 旧测试里依赖旧 `ListTile`、旧状态角标和旧文案的实现断言未更新，完整旧套件可能失败；本次依用户要求使用独立新测试验收。第一阶段审计列出的排版、存储持续失败、签名及工具链风险继续存在。
