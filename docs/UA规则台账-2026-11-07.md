## 两条入口与既有差异

`uaRules()` 以 UA origin 参与完整层叠；`UaBlockDefaults.apply()` 对兼容块路径施加有限默认样式。两个入口均经 `ComputedStyle` 归一断页别名。标题字号、字重、边距与避页底、引用盒、列表容器、表头字体、hr 线框有回归覆盖。

| 块级覆盖入口 | 对应规则 | 已保留差异 |
|---|---|---|
| h1～h6 | UA-019～UA-024 | 同一标题度量与避页底声明 |
| blockquote / figure | UA-011～UA-012 | 同一物理边距；完整 display 由完整层叠承担 |
| figcaption | 无独立完整 UA 规则 | 兼容入口保留上下 1em，不新增完整 UA 规则 |
| pre | UA-011 / UA-014 / UA-060 | 兼容入口只提供字体与边距，空白语义由聚合器承担 |
| ul / ol / dl / dd / dt | 列表规则组 | 兼容入口只提供盒与字体，列表类型由构块职责消费 |
| li | UA-026 / UA-027 | 40px 旧路径近似缩进与 disc 默认；正式章节过滤 UA-027，按容器盒累计缩进并生成标记 |
| th | UA-051 | 兼容入口只提供字重与对齐，格盒由表格职责消费 |
| hr | UA-075 | 两入口相同灰线与高度；完整入口额外提供 gray 文字色 |
| center | UA-018 | 相同居中声明 |
| p / body / html | UA-006～UA-010 | 兼容入口不另施加段距或页根盒；完整层叠与阅读器设置承担 |

有意页边界变化：新旧断页别名开始按层叠优先级共同竞争；`avoid-page` 进入既有 avoid 分页语义；流式入口消费普通分页的图题组、容器续框、盒高、表头和标题避页底。页索引 schema 提升为 6，旧 v5 结果拒绝复用。普通分页算法职责迁移不另外改变断点，结构化同步／流式差分测试检查 CFI、文本、行区间、几何和表格载荷。
