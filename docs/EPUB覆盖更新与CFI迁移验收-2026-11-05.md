# EPUB 覆盖更新与 CFI 迁移验收

日期：2026-11-05。范围：应用内部连续版本更新，不处理跨阅读软件互通。

## 最终行为与实现位置

| 需求 | 实现与结果 |
| --- | --- |
| 同当前 bookId 导入 | 自动覆盖，无确认弹窗；完全相同原文件提示“书籍内容未变化”，不重复迁移 |
| 不同 bookId | 普通导入新增；长按旧书“更新”可强制替换，采用新身份并保持整数主键；新 ID 冲突拒绝且不合并 |
| 内容版本 | 原 EPUB 完整 SHA-256，与 32 位 bookId 分开；新书及覆盖文件写入独立版本目录 |
| 统一位置证据 | `LocationAnchor` v1 保存章节、段落指纹、真实偏移、引用及上下文；原始与最近成功锚点分开保留 |
| 搜索与实际文字 | 索引复用正文解析、作者行内样式、空白及表格文本链路；归一化空白有反向偏移映射，不截断 UTF-16 代理对 |
| 历史数据 | schema 13 → 14 增加版本、锚点与身份别名；旧文件补锚点，书签标签不当正文；旧页号使用设置与当前窗口重建，明确近似来源 |
| 自动定位 | CFI 同时验证内容；章节、段落及全书索引寻找引用，不把合法偏移或第一候选视为成功；改写需双侧唯一长文本证据 |
| 失败与续读 | 标注失败待确认，保留原引用和样式，不画不跳；进度用可靠章节比例或前后相邻已匹配章兜底，并提示近似恢复 |
| 手动重新定位 | 列表展示原因；选择新版文字或当前位置并确认，只修改当前位置；取消不写入，原引用、笔记、样式与时间不变 |
| 覆盖提交 | 同数据库队列串行，提交校验内容版本与用户数据快照；事务统一切换书籍、目录、章节及用户位置；成功后删除旧 EPUB |
| 取消与恢复 | 提交前仅清暂存；事务内取消整体回滚；提交后取消仍为成功，不调用删书；启动扫描保护当前原书和封面 |
| 状态与缓存 | 原用户资料、分组、标签、书评、阅读历史及外键保留；新内容重新计算进度；新增可读内容可使读完转在读，恢复及重排不自动重新标为读完；新源路径、内容版本和布局版本使缓存重新建立 |

核心代码：`packages/reader_core/lib/position/location_anchor.dart`、`revision_relocator.dart`。
移动适配：`apps/reader_mobile/lib/library/revision_anchor_index.dart`、`revision_anchor_store.dart`、`library_revision.dart`，以及进度、书签和标注存储。
界面：`packages/reader_ui/lib/reader_session.dart`、`reader_page.dart`、标注定位/绘制与两个阅读数据面板；书架和详情提供更新入口与待确认原因。

现有 CFI 继续作为应用内部坐标。本次没有把它全面改造成标准互通格式；内容锚点和原文件摘要承担跨版本验证与恢复。

## 自动化覆盖

连续版本样本由 `apps/reader_mobile/test/library/fixtures/revision_epub.dart` 生成真实 EPUB，导入和更新调用正式流程，验证数据库记录及新版实际 CFI 所指文字。

- 核心位置回归覆盖前插、中插、后追加，路径和标题变更，拆章、合并、搬移、删除、跨段/跨章、重复与倒序；包含短端点、恰 16 UTF-16 单元、补充平面字符、空白映射和待确认再次迁移。
- 移动覆盖回归验证实际 EPUB 自动/强制更新、身份冲突、同文件、连续拆合搬移、删除后再次找回、跨段转跨章、原用户字段保持、读完状态、缺旧文件、历史页号、旧会话拒写、队列取消和存储失败。
- 正文索引测试对照实际绘制文本与 CFI，覆盖作者 `pre` / `pre-wrap`、隐藏行内内容、表格单元格及补充平面字符。
- 存储回归验证 schema 13 升级、别名歧义、安全版本绑定、真实内容保存、无效 CFI 保留旧锚点，以及重新定位只改当前位置。
- 阅读界面回归验证低置信度不绘制、不跳转，跨块完整绘制，末页恢复不立即读完，近似提示，笔记/书签重新关联和取消。

菜单组件使用真实 EPUB 构建的锚点索引与确定性内存存储，逐条核验选中文字；数据库事务由存储及覆盖专项测试验证。

## 剩余限制

- 章节缺少不变正文，又沿用原路径或标题时，无法可靠区分替换与新增；同一章删除并新增相同数量段落也可能无法判定新增。读完状态采用保守判定，进度兜底有明确近似提示。
- 旧页号仅能按保存设置与当前窗口重建，无法保证回到原来同一行；缺失或损坏原文件时，无法凭空补出原内容证据。
- 没有执行真实磁盘耗尽、事务边界瞬间杀进程或断电。当前用存储写入失败、事务内取消回滚、遗留目录恢复扫描及提交后重启验证安全路径。
- 真机只完整检查一台竖屏设备；没有全面验收其他平台、横屏、超大书连续覆盖的资源峰值或长期性能。当前不提供撤回，也不自动合并身份冲突的书。
