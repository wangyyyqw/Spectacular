# TXT 导入与章节正则

书架的“导入 EPUB / TXT”支持混选。TXT 在后台识别编码、清理纯空白行、识别目录并生成 EPUB，通过现有 EPUB 校验后加入书架。原文件不被修改。

## 空行与正文

- 首次导入删除所有纯空白行，包括只含空格、Tab、全角空格的行。
- 非空行清除行首空格、Tab 和全角空格；正文统一首行缩进 `2em`、两端对齐，章节标题居中且不缩进。行内空格、文字和特殊字符保留，标题在正文中只出现一次。
- 生成样式只写正文缩进、正文对齐和标题居中。字号、行距、段距、字体和标点压缩使用阅读器现有规则；不声明 `white-space: pre-wrap`，避免绕过普通正文的标点压缩。行内空格保留在源码，显示遵循普通 HTML 空白折叠。
- 无可识别标题时，按约 10,000 个 UTF-16 代码单元分节；单章超过约 50,000 个代码单元时产生续节。目录中的合成标题不额外写入正文。
- 相同原始 TXT 字节按 SHA-256 去重，改文件名后重复导入也不会覆盖已经编辑的 EPUB。编码、换行或正文改变会形成不同来源。

## 目录规则

内置 10 组规则：卷章同一行、中文章回、英文 Chapter/Section/Episode、序章与番外、未命名章节、数字加分隔符、括号编号、纯数字、符号标题、顶格短行。前 7 组参与自动检测；后 3 组可手动选择。

自动识别支持首行标题、简繁中文数字、全角数字、英文罗马数字及卷章层级。弱编号结合格式、连续性和正文间距判断，过滤日期等常见噪声；书首目录仅在后文完整重复时排除切点，原目录文字仍保留。已明确启用的个人规则优先于内置规则。

数字加分隔符的自动识别采用主编号链，允许点号后标题以数字开头，避免正文编号清单借全书平均间距混入目录。已有稳定中文章序列时，正文弱数字小节不自动加入；夹在连续主章之间的异类章、节引文与卷名说明句会被过滤。“未命名草稿／章节”只有在前后同类章号恰好缺一章、两侧都有足够正文时才自动成章。弱编号中的错号、重复号或混合标题格式仍可能漏检，可预览后使用自定义正则；自定义规则严格匹配原文，不执行这些自动过滤。

TXT 来源书籍可从书籍详情、桌面右键菜单或阅读目录进入“章节正则”：

1. 选择自动、内置规则、自定义正则或按长度分节。
2. 点击“预览目录”，检查目录、正文样例和诊断。
3. 点击“应用重新分章”保存；修改规则后必须重新预览。

自定义正则按完整逻辑行匹配，不要求捕获组；命中的原文作为标题。示例：

```regex
[ \t　]*第[0-9０-９零〇一二三四五六七八九十百千万]+章.*
```

分卷正则单独填写；区分大小写由开关控制。默认只修改本书，可“另存为我的规则”，并自行选择是否参与以后 TXT 导入的自动识别。个人规则的增删不会自动改动已有书籍。这里使用 Dart 正则，不执行 JavaScript，也不导入 Legado JSON 规则。

## 保存与重新分章

手动重新分章读取当前已保存的 EPUB，保留已编辑文字和 DOM 中的行内格式、图片、表格、列表、脚注与链接。不会重新读取原 TXT，也不会再次删除用户编辑的空行。表格、列表、脚注和媒体内部不切分。

预览绑定书籍版本；书籍变更、取消、零匹配或校验失败时不切换书架文件。存在编辑草稿时，需要先保存或放弃草稿。应用时迁移进度、书签、批注和装饰，保留书籍身份与用户修改的书名资料，并保留上一版本。无法可靠迁移的位置保留为待定位，不删除记录。右上角菜单可恢复上一保存版本。

跨章节样式不兼容、重复 ID、参与样式的容器 ID 或专用 spine 结构会阻止应用并提示原因，以免静默丢失格式。改变章节边界时，依赖节点顺序的结构选择器与 CSS 计数器也会触发保守拒绝；这项检查可能拒绝未实际命中的规则，不等同于完整的 CSS 视觉等价验证。

## 编码与运行边界

支持 UTF-8、UTF-16LE/BE、GBK（含 GB2312）和 Big5。编码识别使用文件前缀，歧义或解码失败时展示候选样例供重试。GB18030 四字节扩展暂不支持。

文件分块读取，ZIP 按章写出；后台 isolate 仍持有全文解码后的逻辑块，内存随正文长度增加。正则扫描可取消，连续 2 秒没有进度时终止并提示简化表达式。
