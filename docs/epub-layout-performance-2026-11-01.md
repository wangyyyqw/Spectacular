# EPUB 正文排版热路径优化（2026-11-01）

基线 `635d9ac`，承接正文两端对齐与标点空间挤压。本次仅减少重复测量，
不新增排版功能、依赖或设置，不修改 EPUB 解析、原文、CFI、作者样式及
缓存语义。**功能回归通过，原有 8ms 性能预算仍未通过。**

## 改动与边界

- `line_breaker.dart` 只在实际可能绘制连字符时测量其字宽；保留
  `hyphens: auto` 和含软连字符的 `manual` 路径，行内盒仍沿用不叠加断词
  的既有约束。普通段落不再为未使用的连字符创建原生段落。
- `spaced_paragraph.dart` 在同一行的候选宽度探测中复用 `TextPainter`，
  仅重新应用宽度约束；探针只求首行，退出时释放。断点仍由平台决定，
  行尾挤压、相邻组合跨行还原及合法断点检查不变，不自行拆词。
- 首行缩进的头部测量只生成需要的首行，不再先完整排一遍窄宽段落再丢弃
  后续行。含不可断 token 或行内盒时保留完整行表，供 token 合并和盒定位
  使用；余文继续按原宽度排版并映射回原文。
- 新增两项最小回归，固定真实思源宋体在四种窄宽下的既有断点，验证正负
  缩进下长段尾部、硬换行和绘制占宽。没有修改旧快照、0.5 逻辑像素占宽
  容差、分页版本或性能门槛。

## 性能实测

环境：同一 macOS 主机、Flutter 3.47.5 / Dart 3.13.4，Rosetta 测试环境。
基线由 `git archive 635d9ac` 建立独立临时副本，独立生成包配置和构建目录，
确认 `reader_core` 指向副本源码，避免改前测量误用当前实现。
改前、改后在独立进程中交替运行两轮；这些是主机 Flutter 测试数据，
不是移动设备或 GPU 绘制性能。

### 真实字体正文基准

新增 `prose_spacing_bench_test.dart`：完整思源宋体 Regular/Bold，20 段、
每段 100 字符、344 逻辑像素宽、17px 字号、1.6 行高，布局后按 700 高分页。
每个组合预热 5 次、采样 11 次取中位数；同时检查分页非空及重复构建的
几何指纹一致。四种组合均产出 4 页。耗时单位为 ms。

| 策略 / 缩进 | 改前 1 | 改后 1 | 改前 2 | 改后 2 |
| --- | ---: | ---: | ---: | ---: |
| 相邻挤压 / 0px | 14.342 | 13.290 | 13.521 | 13.116 |
| 相邻挤压 / 34px | 29.218 | 26.113 | 29.951 | 26.085 |
| 相邻及行边挤压 / 0px | 46.699 | 34.005 | 47.547 | 33.643 |
| 相邻及行边挤压 / 34px | 80.527 | 37.720 | 80.990 | 37.415 |

相邻及行边挤压无缩进时耗时下降 **27.2%–29.2%**，有缩进时下降
**53.2%–53.8%**。不据此推断任意 EPUB 或字体都能获得相同比例收益。
该基准默认跳过，显式运行不会替代原有预算检查。

### 原有预算：仍未通过

原有 Ahem 基准、预热和取样次数不变，门槛仍为 8 / 4 / 1000ms。
第三项实际是 100 段布局加分页，不能当作 GPU 首帧耗时。

| 轮次 | 20 段布局加分页 | 缓存命中 | 100 段章节构建 |
| --- | ---: | ---: | ---: |
| 改前 1 | 10.026 | 0.009 | 45.143 |
| 改后 1 | 8.441 | 0.010 | 40.401 |
| 改前 2 | 9.305 | 0.010 | 44.996 |
| 改后 2 | 9.092 | 0.010 | 41.517 |

四次预算命令均因 20 段构建超过 8ms 退出 1。普通段落耗时有所改善，但
测试波动明显，不宣称达到性能预算，也不把基线已存在的超预算归因于
本次优化。没有通过调整环境变量提高门槛。

## 复现

以下 Flutter 命令依次执行，不与其他性能采样、CSS 导出或全量测试并行。

```sh
# packages/reader_core
PROSE_BENCH=1 flutter test --no-pub test/bench/prose_spacing_bench_test.dart -r expanded
BUDGET_RUN=1 flutter test --no-pub test/bench/budget_test.dart -r expanded
# 三包目录各自执行
flutter analyze --no-pub
flutter test --no-pub -r expanded
# apps/reader_mobile
REAL_EPUB=1 flutter test --no-pub test/real_book_sweep_test.dart \
  test/m1_integration_test.dart -r expanded
# 仓库根目录
bash tool/check_core_boundary.sh
bash tests/analysis/verify_strict_flags.sh
```

本轮日志位于 `/tmp/epub-perf-prose-{before,after}-{1,2}.log`、
`/tmp/epub-perf-budget-{before,after}-{1,2}.log`、
`/tmp/epub-perf-final-reader_{core,ui,mobile}-{analyze,test}.log` 和
`/tmp/epub-perf-final-real.log`；CSS 产物在 `/tmp/epub-perf-css-{before,after}`。
临时采样脚本、日志、截图和构建产物不入库。

## 未处理风险与下一步

- 8ms 预算仍未达标；剩余热点主要在平台字体塑形、行度量及断点查询。
  本次未用全局字体缓存或自研断行替换平台行为，以免扩大字体失效和禁则风险。
- 未做移动设备性能、真机视觉或安装包验收；未知字体与缺少语义标记的
  特殊段落仍沿用上轮已记录的限制。
- 下一步优先在目标移动设备采样长章节、混合字号与浮动场景，再决定是否
  需要进一步减少平台测量调用，避免仅凭桌面微基准进行架构改动。
