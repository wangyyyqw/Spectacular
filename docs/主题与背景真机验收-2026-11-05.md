# 主题与背景真机验收（2026-11-05）

## 变更

- 优化五套内置主题：白 `#FAF9F6 / #282622`、米黄 `#EEE4D0 / #41382B`、灰 `#E2E3DF / #333631`、深色 `#202320 / #C4C6BD`、纯黑 `#000000 / #BABDB7`。正文与纯色底的对比度为 9.12–14.34:1；页眉页脚保留正文色 76% 不透明度，五套均达到 4.5:1。
- 内置纹理保留 10% 强度，用户图片保留 18% 强度，均混合当前主题底色。修复深色、纯黑配浅色纸纹时背景盖住正文的问题。图片按原比例居中裁切铺满，内置纹理继续平铺。
- 新增“自定义配色”：分别修改背景色、文字色，支持六位十六进制和 RGB 滑块、即时预览、明暗对比提示、保存与取消。保存后出现“自定义”主题；切换内置主题仍可复用。沿用设置表保存颜色，无数据库结构或依赖变化。
- 新增“选择背景图片 / 更换背景图片”：复用系统文件选择器，接受 JPG、JPEG、PNG、WebP，大小上限 20MB；复制首帧到应用目录，最长边限制 1600px，关闭原文件选择器、重开书和重启后仍可恢复。
- 背景解码成功后才持久化，取消和损坏图片不覆盖当前有效背景；最新请求优先，过期请求释放图片，解码器和图片句柄按生命周期释放。恢复缺失图片时显示主题纯色并提示重新选择。
- 修复移动阅读页始终使用开书时设置快照的问题，连续修改主题、背景等设置现在基于当前状态；设置保存串行执行。清理一天前的废弃背景时同时保护已保存与待保存的图片。
