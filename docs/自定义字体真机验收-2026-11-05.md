# 自定义字体与内嵌字体覆盖验收

入口为阅读菜单 → 排版 → 导入字体。支持 TTF/OTF，单文件不超过 50MB。导入后复制至应用目录，按内容摘要去重，重复导入保留首次名称。选择已有字体先完成校验及注册，再应用排版；取消、损坏文件和加载失败均不替换当前字体。打开书籍时恢复所选字体，文件丢失或内容改变时提示并回落书籍字体，重新导入可修复过期路径。

默认只替换未内嵌字体，成功加载且可解析字形的书内字体继续使用。仅 `local()`、资源缺失及损坏字库不视为可用内嵌字体。“全书使用自定义字体”开启后覆盖正文、标题、表格、行内元素和伪元素的字族，保持作者字号、字重、行高及盒样式。关闭开关恢复内嵌字体。字体和开关参与分页指纹，沿用重排与 CFI 锚点保护。CSS 字体简写及变量引用都进入实际字体映射，保留内嵌字体的完整回退链；用户字体缺字沿用已有逐字回退。
