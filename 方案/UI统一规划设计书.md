# Spectacular UI 统一规划设计书

日期：2026-11-21  
设计依据：当前书架源码、MEIZU 20 上的实际书架界面与现有功能入口。  
执行顺序：先形成本文，再实施；本文是本次界面调整的唯一设计依据。

## 1. 目标与边界

让统计、笔记与书评、我的、图书详情、阅读面板、EPUB 工具和 TXT 导入呈现同一套书架视觉语言。短操作、选择、详情和表单优先使用抽屉，用户关闭后回到原来的书籍、列表位置和阅读上下文。

本次采用界面统一与局部交互调整：复用 Flutter、`AppIcon`、现有主题和抽屉底板，不引入依赖，不改变数据库、EPUB 解析、排版与分页架构。所有现有功能和真实保存入口均保留。

设计定位：面向本地阅读用户的纸白墨黑界面；布局变化程度 4/10；沿用书架的文字页签、轻分隔和封面作为视觉识别。动效只服务抽屉进出和状态切换。

## 2. 书架视觉基准

以 `apps/reader_mobile/lib/theme/app_theme.dart` 和 `lib/home/bookshelf_page.dart` 为真源，不另选品牌色、字体或组件库。

| 类别 | 日间 | 夜间 | 使用规则 |
| --- | --- | --- | --- |
| 页面画布 | `#F6F6F4` | `#1B1D1F` | 主页与完整页面背景 |
| 内容表面 | `#FFFFFF` | `#222427` | 列表、表单与抽屉 |
| 主文字与主要操作 | `#222427` | `#E7E8E4` | 标题、选中项、确认按钮 |
| 次级文字 | `#686C71` | `#B1B4B4` | 作者、说明、日期、单位 |
| 浅填充 | `#F0F1EE` | `#2B2D30` | 搜索以外的选项底板、选中行 |
| 分隔线 | `#E4E5E2` | `#3B3E42` | 分区与列表细线 |
| 错误 | `#B34338` | `#F0AAA0` | 仅错误与破坏性操作 |

原始颜色由 `ColorScheme` 映射为语义角色，组件读取角色，不复制一套色值。封面、用户选择的标注颜色、正文预览和图表区分数据所需的颜色可以保留，不增加装饰性彩色底板。

| 项目 | 基准与执行要求 |
| --- | --- |
| 界面字体 | 复用已打包的 `builtin_hei`；目录、搜索和表单不强制使用 `serif` |
| 页面标题 | 22，w600；左对齐 |
| 行标题、正文、抽屉标题 | 14；需要强调时 w600 |
| 作者、说明、日期 | 12；底栏等辅助标签沿用 11 |
| 数字 | 阅读时长与统计继续使用等宽数字字形 |
| 页面间距 | 手机水平 16；区间 24；行内 8/12/16；桌面内容居中限宽 |
| 普通控件 | 圆角 4，无额外投影 |
| 搜索与圆形快捷操作 | 保留书架实际的圆角 20 和轻投影，不扩大到内容分区 |
| 抽屉 | 沿用现有实色底板和顶部圆角 24；不采样正文背景 |
| 图标 | 统一 `AppIcon/AppGlyph`；图标按钮提供中文提示与至少 44 的操作范围 |
| 选中状态 | 墨色文字、字重或浅色底板；不增加彩色胶囊或绿色选中环 |

全局主题中旧有的底部弹层圆角 8 被正式抽屉包装覆盖，本次以实际生效的 24 为准。阅读正文的字体、主题和作者 CSS 独立；阅读控件保留日夜与自定义配色适配，统一字体层级、控件形状和操作方式。

## 3. 页面与抽屉规则

### 3.1 保留完整页面

四个一级入口保持书架、统计、书评、我的。阅读正文、EPUB 源码工作台、TXT 章节正则预览、图片查看、需要整页定位的边距与点击区域预览继续使用完整页面。这些操作需要持续阅读、长时间输入或完整空间。

### 3.2 优先使用抽屉

手机使用底部抽屉；桌面二级任务使用靠右的抽屉，窄窗口限制宽度并保持内容可滚动。公共入口复用现有底板、主题捕获和路由返回值。

| 类型 | 适用任务 | 行为 |
| --- | --- | --- |
| 短操作抽屉 | 排序、主题、编码、工具选择 | 标题、可见选项、关闭；选中后返回结果 |
| 内容抽屉 | 日历详情、时长明细、笔记、书评、诊断日志 | 标题固定，长内容滚动；回到来源位置 |
| 表单抽屉 | 书评、自定义主题、元数据、章节与目录工具 | 标题与关闭、滚动表单、明确取消和保存/应用 |
| 短确认弹窗 | 删除、放弃草稿、恢复版本、清理日志 | 沿用确认框；写明后果和具体操作动词 |

普通抽屉支持可见关闭、系统返回、遮罩关闭；手机短抽屉可下拉关闭。现有有草稿保护的编辑器禁止误触遮罩或拖拽丢失内容，返回时仍走原有放弃确认。

键盘出现时按可见高度布局，输入和底部操作保持可达；长标题允许换行。调用方持有的输入控制器必须等抽屉退场、输入控件卸载后再释放。关闭后恢复原页面焦点，遮罩不透传桌面快捷键。

```text
手机表单抽屉                         桌面二级抽屉
┌──────────────────────────┐       ┌───────────────┬─────────────────────┐
│ 原页面，保留当前位置      │       │ 原页面遮罩     │ 标题            关闭 │
├──────────────────────────┤       │               ├─────────────────────┤
│ 标题                 关闭 │       │               │                     │
├──────────────────────────┤       │               │ 可滚动内容或表单     │
│ 可滚动内容或表单          │       │               │                     │
│                          │       │               ├─────────────────────┤
├──────────────────────────┤       │               │ 取消        保存/应用 │
│ 取消            保存/应用 │       └───────────────┴─────────────────────┘
└──────────────────────────┘
```

## 4. 各页面设计

### 4.1 统计

保留图书时长、阅读日历、每日平均、阅读排行和最近阅读的现有顺序及数据口径；不恢复此前已移除的摘要或增加指标卡。手机内容边距与书架统一为 16，桌面保留现有双列图表。

时间段、月份和排行的现有抽屉继续保留。“查看全部”的图书时长明细、点击星期后的分时阅读明细改用内容抽屉；现有图表、有效会话与书籍跳转行为保持。

```text
统计                              刷新
图书时长                       周期选择
  原有图表 / 查看全部 → 明细抽屉
──────── 轻分隔 ──────────────────
阅读日历                      月份选择
  原有日历 / 日期 → 当日内容抽屉
──────── 轻分隔 ──────────────────
每日平均、阅读排行、最近阅读
```

### 4.2 笔记与书评

保留同一入口下的笔记和书评两页签。页签改为书架式文字选中，取消包裹整个页签的胶囊底板；搜索沿用书架搜索框。书评排序改为可直接浏览全部选项的抽屉。

笔记继续按书展示实际标注与装饰数量。书评保留封面、评分、正文状态、日期和阅读时长；票签底板统一为中性表面，避免随封面变化的大面积彩色渐变。评分通过墨色实心与空心星区分。

查看书评、写书评、按书查看笔记共用适配手机和桌面的内容/表单抽屉。保留已读完才能写书评的条件、保存失败保留草稿、放弃修改确认及删除确认。

### 4.3 我的

沿用应用信息、外观、阅读、帮助与诊断、关于的功能顺序。内容居中限宽，手机边距 16；设置使用简洁行式分区、白色表面和细分隔，避免装饰性卡片与大面积彩色图标。

界面主题、书架排序改为短选择抽屉，当前选择明确标记。诊断日志改为可滚动、可选择文本的内容抽屉；导出沿用真实分享入口，清理仍需确认。保存中的操作沿用原有状态。

### 4.4 图书详情与读完

书架长按的快捷操作抽屉保留入口与原书籍身份；从中进入完整详情时使用较高内容抽屉。详情继续提供封面、资料编辑、标签、章节正则、阅读记录和书评；标题与关闭在顶部，保存使用真实存储。

资料与说明采用书架的 14/12 层级，不改变封面比例或删减信息。章节正则与源码编辑仍进入完整页面。读完与书评已有抽屉保持，评分和说明对齐统一视觉。

### 4.5 阅读控件

保留目录/书签/标注/装饰/搜索所在的已有目录抽屉，以及主题、排版、设置的主抽屉入口和固定底部导航。

目录条目、搜索框、标注搜索和装饰搜索去掉强制衬线字体，继承界面字体。分隔、文字和选中项统一读取主题语义角色。主题选中环使用墨色；主题预览继续显示真实的用户配色。

自定义主题由中心表单改为抽屉，保留颜色预览、十六进制输入、RGB 调整、清晰度提示和保存/取消。字体、书签、标注和装饰编辑本来就是抽屉，继续复用，避免重复改导航。

### 4.6 EPUB 工作台与工具

源码、预览和桌面停靠文件导航保留。元数据、样式、章节、目录、查找替换、图片和本地工具表单使用统一表单抽屉；工具列表、处理结果使用内容抽屉。

表单字段、内容、按钮与错误保持真实功能。源码和 HTML 输入保留等宽字体；正文/字体预览保留被编辑内容的字体。确认修改、删除和放弃继续使用短确认框。外部输入控制器保留退场后释放的约定。

### 4.7 TXT 导入与章节规则

编码选择改为包含候选项和真实正文样例的抽屉，确认后继续原导入任务。章节规则另存、管理改为表单/内容抽屉，沿用原规则校验与存储。

长目录预览、正则编辑及应用后查看章节保持完整页面。恢复版本使用短确认，不改变书籍固定身份或阅读数据迁移。

## 5. 状态与可访问性

| 状态 | 设计与保留行为 |
| --- | --- |
| 加载 | 复用现有骨架或进度指示，不把真实内容替换为占位数据 |
| 空列表 | 说明无记录的实际原因；保留搜索重置、导入或返回入口 |
| 无搜索结果 | 保留清除关键词/重置筛选入口 |
| 保存失败 | 原表单与草稿保留，给可重试的中文提示 |
| 处理失败 | 沿用工具错误与结果输出，不伪造完成状态 |
| 未保存退出 | 保留已有草稿确认，不把返回与关闭变成静默丢弃 |
| 夜间与自定义主题 | 使用语义色；底板、文字、边界和错误均可辨认 |
| 大字号/窄屏/键盘 | 内容可滚动，标题与操作不相互覆盖 |
| 桌面键盘 | Tab 焦点留在当前弹层，Escape/返回遵守草稿状态 |
| 减少动态效果 | 关闭抽屉进出动效；其他动效复用已有设置 |

## 7. 验收与交付

1. 运行正式 UI 入口的最小回归：抽屉返回值、键盘与焦点、退场后的控制器释放；书评保存/放弃；主题和排序保存；详情与统计明细；EPUB/TXT 工具的真实调用。
2. 复用受影响路径现有测试，两个改动包各做一次静态分析；不运行 EPUB 引擎全量测试，因为本次不改变解析、测量、布局或绘制。
3. 按 `tool/build_apk.sh` 的正式 Release 流程优先离线缓存打包，Pub 使用 `--no-pub`，Gradle 使用 `--offline`。
4. 真机安装前正常退出阅读页，记录书架身份/数量、界面与阅读设置、本书保存位置和已有标注/书签的一次最小基线；相同包名覆盖安装，保留应用数据。
5. 真机检查书架、统计明细、书评、我的设置及阅读抽屉；验证关闭返回、长内容滚动、键盘输入、日夜主题和数据保留。EPUB/TXT 的长表单通过对应测试与可用样本验证。
6. 截图、APK、测试输出和最小数据对照存入被忽略的 `apps/reader_mobile/dist/`，不提交构建产物、日志、数据库或用户 EPUB。

验收结论只覆盖实际检查的页面和状态。若某一平台或流程未实测，明确记录，不将手机与组件回归等同于全部桌面系统已验收。
