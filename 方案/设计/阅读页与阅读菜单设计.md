# 阅读页与阅读菜单设计（P8-10 页眉页脚扩展 + 菜单态）

> 状态：**设计稿，未实现**。参考：用户提供的商业阅读器截图两张（纯阅读态 + 菜单态）。
> 对应任务：P8-10 页眉页脚 6 槽扩展实现、P4-11 目录面板、P4-21 设置面板、P4-22 主题切换的前置 UI 规格。
> 实现约束：沿用现有 `ReaderView` 手势分区（tapLeft/tapCenter/tapRight，`safeEdge=24` 逻辑像素）与 `onToggleToolbar` 回调（已定义未接线）。

## 1. 两种状态

| 状态 | 系统栏 | 页眉/页脚信息槽 | 菜单层 | 进入/退出 |
|---|---|---|---|---|
| **沉浸态**（默认） | 隐藏（immersiveSticky） | 显示（页面同色，弱化文字） | 无 | 冷启动/退出菜单 |
| **菜单态** | 显示（浅色图标，透明背景） | 被顶部菜单遮盖 | 顶部栏 + 底部栏 | 点屏幕中央；点中央或返回键收起 |

- 沉浸态下系统栏隐藏（现有 immersiveSticky 已实现），信息槽常驻——阅读中随时可见章节/进度，无需呼出菜单。
- 菜单态退出沉浸（系统栏临时显示），菜单收起时恢复沉浸。系统栏背景透明，与页面背景连成一体。

### 2.1 页眉槽（页面上缘，正文区内顶部）

| 槽位 | 内容 | 样式 |
|---|---|---|
| 左 | 当前章节名（如「第270章 张木匠」） | 13sp，主题 text 色 45% 透明度，单行省略 |
| 右 | 全书进度百分比（如「37.35%」） | 同左 |

- 随阅读主题换色（黑主题下为浅色低透明度），与正文同底色。
- 章节切换/进度更新时刷新，不触发重排（绘制层文本，不进分页几何——与现有页脚第一槽同机制）。

### 2.2 页脚槽（页面下缘，正文区内底部）

| 槽位 | 内容 | 样式 |
|---|---|---|
| 左 | 系统时间（HH:mm）+ 电量图标/百分比 | 13sp，同页眉弱化样式 |
| 右 | 本章剩余页数（「本章剩余 3 页」） | 同左 |

- 时间每分钟刷新（Timer，仅刷新该槽文字，不重排）。
- 电量走 platform 电量插件或 stream（后续接入，先占位文字）。
- 现有页脚「第 x/y 章 · a/b 页」第一槽**替换**为本设计：左=时间+电量、右=剩余页数；章码/页码合并进进度百分比语义（页眉右已表达全书进度，避免重复）。

### 2.3 6 槽系统映射（对齐 Reeden 520 号）

| 槽 | 位置 | 内容 | 本期 |
|---|---|---|---|
| 1 | 页眉左 | 章节名 | ✅ 本设计 |
| 2 | 页眉右 | 全书进度 % | ✅ 本设计 |
| 3 | 页脚左 | 时间 + 电量 | ✅ 本设计 |
| 4 | 页脚右 | 本章剩余页数 | ✅ 本设计 |
| 5 | 页眉中（预留） | 书名（可关） | 后续设置项 |
| 6 | 页脚中（预留） | 累计阅读时长 | 后续设置项 |

- 每槽可独立开关（P4-21 设置面板的「页眉页脚」分组）。

## 3. 菜单态布局（对应参考图二）

```
┌──────────────────────────────────┐
│ （系统状态栏：时间/信号/电池）    │ ← 系统栏临时显示
│ ┌──────────────────────────────┐ │
│ │ ←  非正常美食文    ☀  🎧  ⚙ │ │ ← 顶部菜单栏（§3.1）
│ └──────────────────────────────┘ │
│   性，出门找秦奶奶要本子。        │
│   ……（正文原样可见，不重排）     │
│                                  │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ ‹  ────●────────────────  › │ │ ← 进度滑杆（§3.2）
│ │                              │ │
│ │ 📖 目录  🎨 主题  ≡≡ 排版  ✦ 装饰 │ ← 四入口（§3.3）
│ └──────────────────────────────┘ │
│        （手势条）                │
└──────────────────────────────────┘
```

### 3.1 顶部菜单栏

| 区域 | 元素 | 行为 |
|---|---|---|
| 左 | 返回箭头（24dp 图标） | 退出阅读页回书架 |
| 左中 | 书名（16sp，单行省略，maxWidth ≈ 55%） | 静态 |
| 右 | 亮度图标 ☀ | 弹亮度滑杆（后续；先占位） |
| 右 | 听书图标 🎧 | TTS 入口占位（P6 TTS 任务） |
| 右 | 设置图标 ⚙ | 排版/设置面板（同底部「排版」入口） |

- 背景 = 主题 background 不透明色；文字/图标 = 主题 text 色。
- 高度 56dp + 系统状态栏高度（菜单态状态栏显示，需 padding 避让）。

### 3.2 进度滑杆

- 结构：`‹` 上一页、拖动轨道、`›` 下一页（左右箭头点击翻页）。
- 轨道：高 4dp 圆角，填充比例 = 全书当前页 / 全书总页（跨章连续虚拟页号 / mappedPageCount）。
- 拖动：松手后跳转到目标虚拟页（复用 VirtualPager.goTo）；**拖动过程中仅更新气泡文字预览（章名+页码），不实际加载**（P4-12 跳转加载体验的前置）。
- 拖动中正文保持原页显示，松手跳转。

### 3.3 底部四入口

| 入口 | 图标 | 面板 | 任务映射 |
|---|---|---|---|
| 目录 | 📖 | 章节列表（当前章高亮，点击跳章；可含书签分组） | P4-11/13 |
| 主题 | 🎨 | 五主题色块 + 沉浸/系统栏开关 | P4-22 |
| 排版 | ≡≡ | 字号/行距/页边距/对齐/字体 | P4-21 |
| 装饰 | ✦ | 注音/着重号/下划线样式开关 | 后续 |

- 四面板均为**底部上滑抽屉**（高度 ≤ 60% 屏高，圆角顶，主题背景色），不整页跳转。
- 面板打开时菜单态保持（顶部栏仍在）。

### 3.4 交互细节

| 动作 | 行为 |
|---|---|
| 沉浸态点中央（tapCenter） | 弹出菜单（顶部栏下滑入、底部栏上滑入，各 180ms；同时退出沉浸显示系统栏） |
| 菜单态点中央 | 收起菜单（滑出动画 + 恢复沉浸） |
| 菜单态点左右区 | 仍翻页（菜单不拦截翻页手势） |
| 菜单态系统返回键 | 收起菜单（不退出阅读页） |
| 音量键 | 预留（翻页快捷键，设置开关） |

- 菜单出现期间**暂停自动息屏**（保持 wakelock，可选设置）。
- 菜单与内容层分离：菜单为 Overlay/Stack 上层，不进入分页几何。

## 4. 主题联动

- 菜单背景/文字/图标全部取自当前 ReaderTheme（白/米黄/灰/深/黑五套）——黑主题下菜单为深色底浅色字。
- 系统栏图标亮度随主题切换（黑主题用浅图标）：`SystemChrome.setSystemUIOverlayStyle`。
- 主题切换即时生效（现有 ColoredBox 打底已联动），菜单无需重建。
