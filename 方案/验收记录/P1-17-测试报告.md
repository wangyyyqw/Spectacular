# P1-17 测试报告：文档树不变量

> 日期：2026-10-23　执行人：Lead　任务：P1-17（2h）

## 1. 范围

新增 `packages/reader_core/test/parser/tree_invariant_test.dart`，对本地样本库全部书籍、全部 spine 章节执行不变量检查：

- 节点树遍历：每个节点只出现一次，父子关系可完整遍历；
- 文本节点：非空串、源码起止位置不倒置；
- CFI：可解析、itemref 与章节一致；
- 块节点 CFI 在文档顺序下严格递增；
- 聚合文本块：非空、runs 不越界/不重叠、hardBreak 指向 `\n`；
- `plainText` 与文本块拼接一致；
- `nodeAtCfi` 能命中原文本节点。

违规日志包含书名、spine 序号、节点路径与 CFI，可直接定位。

## 3. 发现并修复的问题

1. **聚合文本 CFI 回退错误**：`TextAggregator` 对无来源文本（如纯 `<br>`）回退到硬编码 `itemRef(2)`，导致跨章 CFI itemref 错误；改为使用所在块的 CFI。
2. **重复 id 定位错误**：`nodeAtCfi` 遇到断言 id 时无条件跳到 `elementsById` 的首次出现，重复 id 的书会定位到错误节点；改为“索引命中优先，id 仅作为缺失/不匹配时的兜底”。

## 4. 已知限制

- CFI 单调性只对块节点检查：按 CFI 规范，文本块与元素使用独立的奇/偶步进，混合内容下数值比较不等价于文档顺序。
- 未对每个元素做 `nodeAtCfi` 反向检查（文本节点已全覆盖）。
- 重复 id 仍以首次出现登记，锚点语义存在歧义；后续目录/脚注跳转需要按索引优先。
- 只覆盖解析/聚合树，不涉及样式、布局树的不变量（§81.8 其余条目）。
- 依赖本地样本库，CI 无样本时跳过。
