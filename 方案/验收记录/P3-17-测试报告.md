# P3-17 测试报告：实现表格两遍测量与列宽

任务：第一遍内容自然宽，第二遍按 table 宽或列比例分配（P3 任务书 ｜ 预算 4h）

## 交付

- `packages/reader_core/lib/layout/table_layout.dart`
  - `TableMeasurer.measureColumns`：第一遍列自然宽 = 行内最大（max-content）；第二遍按表声明宽分配——声明列保留（超表宽等比缩）、auto 列分剩余空间（自然比例加宽 / 超宽按自然比例压缩 / 无自然宽均分）、auto 表宽 = min(自然和, 容器)、百分比表宽 = 容器 × 百分比
  - `TableMeasureResult`：列宽数组 + 表宽
- 测试：`test/layout/table_layout_test.dart`（6 用例）

## 验收对照

| 验收项 | 结果 |
|---|---|
| 固定宽表列宽正确 | ✅ 声明列 60 保留，剩余 240 按自然比 200:120 → 150:90 |
| 百分比宽表列宽正确 | ✅ 表宽 = 320×50% = 160，自然和 200 等比压缩到 80:80 |
| auto 表列宽正确 | ✅ 自然和 220 ≤ 容器用自然宽；240+240 超容器等比压到 160:160 |

## 关键实现决策

1. **纯函数测量器**：输入第一遍自然宽 + 声明值，输出列宽——与单元格布局（P3-18）和 TableFlowBlock 接线解耦；单元格内容测量复用现有两阶段块测量。
2. **无 auto 列不强制铺满表宽**：全列有声明且总和不超表宽时保持声明值（右侧留白），与 CSS fixed 布局语义一致；发现并修正了实现中该分支错误按自然宽覆盖声明值的缺陷（用例锁定）。
3. **超宽表策略**：本任务按容器收窄（§8.5）；Reeden 140 号 D51「整表等比缩放」作为候选策略记录，与 UA 默认值（P3-21 裸表格）一并评估。
