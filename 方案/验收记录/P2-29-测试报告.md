## 1. 实现（`packages/reader_core/lib/paint/page_renderer.dart`）

- 新增 `PagePaintPhase`：`background → blockBackground → blockBorder → text → decoration → selection`，`PagePainter.paint` 按固定顺序执行，阶段开始时可回调 `onPhase`（测试/调试用，默认 null 不影响生产）。
- 结构改造：
  - 先统一预计算每片切片的几何与样式（`_SliceGeometry`：位置、样式、行内文本样式、首尾块标记、可见性、首行内缩、上下标越界），六个阶段共用同一份坐标，不再在各阶段重复计算；
  - **块背景**与**块边框**拆成两遍独立循环（原来与文字逐块混合）；
  - **文本**阶段只画文字（`_paintLineText`）；
  - **装饰**阶段单独画着重号（`_paintLineEmphasis`），只对声明了 `text-emphasis` 的块执行，避免无谓重建 `TextPainter`；
  - **选区**阶段最后绘制，覆盖所有内容。
- 新增选区模型：`PageSelection` / `SelectedTextRange`（切片序号 + 块内字符范围），`PagePainter` 增加 `selection` 与 `selectionColor`（默认半透明蓝 `0x330066FF`），按行取排版盒绘制高亮矩形。
- 保留既有行为：跨页裁剪、`visibility: hidden` 跳过背景/边框/文字、上下标越界放宽裁剪、主题文字色覆盖、背景裁剪/定位语义。

## 4. 已知限制

- `text-decoration`（下划线/删除线）仍由 `TextStyle.decoration` 在**文本阶段**随字形绘制，没有单独成遍；若要严格「文本后再画装饰」，需要自定义画线（P3 样式完善时再处理）。
- 选区模型尚未接入 UI（`ReaderPage` 没有选区参数）；本任务只提供绘制能力与顺序保证。
- 选区实现会为每个覆盖行重建一次 `TextPainter`，选区频繁拖动时可缓存（当前页面级开销可接受）。
