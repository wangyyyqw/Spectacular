## 1. 实现

- CSS 层（`computed_style.dart`）：
  - `textDecoration`（不继承：none/underline/lineThrough/overline）；
  - `textEmphasisStyle`（继承：none/dot/filled/open，支持 `text-emphasis` 简写与 `sesame/circle` 别名）、`textEmphasisPosition`（继承：over/under）、`textEmphasisColor`（继承，null 跟随文字颜色）；
  - `pageBreakBefore`/`pageBreakAfter`（`page-break-before/after` 与 `break-before/after`，always/page/left/right → true）、`breakInsideAvoid`（`break-inside`/`page-break-inside: avoid`）。
- 测量层：`textStyleFor` 把 `textDecoration` 映射为 Flutter `TextDecoration`（下划线/删除线/上划线，逐 run 生效，颜色取文字色）。
- 绘制层（`page_renderer.dart`）：`_paintEmphasis` 按字符取排版盒，在上/下方画实心（dot/filled）或空心（open）圆点；半径 `0.08em`、位置 `over = 盒顶 + 0.15em`、`under = 盒底 − 0.15em`；每行只画本切片可见的行，装饰不跨页重复。
- 分页层（`paginator.dart`）：`PageBlock.breakInsideAvoid`（`PageBlock.styled` 从样式读取，`page-break-before/after` 同样从样式读取）；分页器在块不能整块放进当前页、但能整块放进新页时先收页，块高于整页时退回按行拆分。

## 2. 与阅微的对照

| 维度 | 阅微 | 我们 |
|---|---|---|
| page-break-before/after | `Auto/Always` 两个取值，参与分页 | 解析 always/page/left/right，`PageBlock` 已有字段并接线 |
| text-decoration | `None/Underline`（Compose `TextDecoration`） | 四种取值映射 Flutter `TextDecoration`，逐 run 生效 |
| text-emphasis | `Style/Color/Position`，字号 `fontSize/2` 区域绘制 | 四种样式（dot/filled/open）+ over/under + 颜色，按字符画点 |
| break-inside | 无该属性 | 新增 `avoid` 语义（能整块放下才不拆） |

## 5. 已知限制

- `text-decoration` 用 Flutter 引擎绘制：线宽/偏移由引擎决定，未实现 CSS `text-decoration-thickness/offset/style`（虚线/双线）。
- 逐 run 装饰依赖 `StyledRun`，行内元素样式尚未逐节点下发（与 P2-16 同一限制）。
- 着重号按 UTF-16 码元逐字符绘制，代理对（emoji）会被拆成两个点；`text-emphasis` 简写里的颜色/位置未解析。
- `break-inside: avoid` 只处理「块整体」；多块组合（如「标题+首段」不分离）需要 `break-after: avoid` 组合，未实现。
- 跨页装饰不重复依赖按行裁剪：装饰随行绘制，切片之外的装饰不会绘制，因此不需要额外去重逻辑。
