# P0-15 翻页原型验收记录

> 任务：P0-15。日期：2026-10-22。执行人：Lead。

## 1. 结论

**在 macOS 桌面通过。** 200 次快速滑动共采集 6,403 帧，无“连续 3 帧超过 16ms”：

| 指标 | 数值 |
|---|---|
| 采样帧数 | 6,403 |
| 中位帧耗时 | 0.8 ms |
| P95 | 1.9 ms |
| 最大帧耗时 | 244.2 ms（首帧/启动阶段，非连续） |
| 连续 >16ms 的最大帧数 | 2（要求 <3） |

页码与内容一致性由 3 个组件测试覆盖：初始第 1 页、左滑到第 2 页、跳转到第 200 页，标题与页面文本一致。

## 4. 限制

- 这是桌面 Debug 数据，不能替代移动端 release/profile 验收；移动端在 P1-34 / M0 真机任务复测。
- 最大 244ms 出现在启动阶段（首帧、字体与 Metal 初始化），不作为滚动卡顿判定；判定看连续长帧。
- 原型只渲染静态页码与背景色，不含真实排版与绘制；真实页面的帧预算由 P1-34 验证。
