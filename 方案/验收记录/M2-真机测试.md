## 5. 验收期发现并修复的缺陷

1. **flat 管线块级 margin.left 未进绘制几何**（`page_renderer.dart`）：`_SliceGeometry.box.left` 恒 0，UA `li/blockquote` 的 40px 左缩进不生效、列表标记 gutter 被吞导致标记与首字重叠。修复：margin.left 折算进几何 `leftInset`（文本 x / 标记 gutter / 选区 / 省略宽度同步右移），背景与边框改用 `marginBox`；`margin.right` 与 `padding.right` 同样暂不参与右侧收窄（flat 管线既有近似，注释已记录）。回归用例：`list_marker_test.dart` 新增「blockquote 包裹段落：容器左右边距叠加到子块（flat 管线）」。
2. **陈旧 APK 干扰判读**：首轮模拟器验证使用 P3-23 之前构建的旧 APK（kernel_blob 符号比对确认缺 `listMarker/_ListContext/EpubRejectionMessages`），列表标记缺失系包旧而非代码缺陷；重建后复验通过。验收流程改进：上机前用 `unzip -p app-debug.apk assets/flutter_assets/kernel_blob.bin | grep -c <新符号>` 校验包新鲜度。
3. **无 OPF 兜底书标题抢占 fallbackTitle**（`importer.dart`）：`buildFallbackPackage` 硬编码 `title: '未命名书籍'`，使 `library_store` 的「文件名 → 未命名书籍」兜底链失效。修复：兜底包标题改空串，由调用方兜底。corpus C 导入后标题行为回归由 `m2_integration_test` 覆盖。

另记录两个观察（不阻塞验收）：
- 系统文件选择器 Downloads 网格顺序不稳定（按 mtime），自动化点按前须先截图定位卡片，人工测试注意认准文件名。
- 阅读页右区点击在屏宽 48 逻辑像素安全边内不响应（`safeEdge` 防误触设计），自动化需点 x < width−24×DPR 区域。

## 7.1 平面管线图片块接入（用户反馈「只看见文字」后追加，2026-10-25）

用户在模拟器翻阅诸神愚戏后反馈「图片表格等等样式都没有，只看见文字」。解包分析：1541 章中 **1515 章含 `<img>`**（108 张位图：90 jpg + 18 png，防盗版混淆的 `*`/`:` 超长文件名）、64 章含 `<table>`、仅 1 个 SVG。根因：**app 阅读的 flat 管线把行内 `<img>` 只聚合为 `[OBJ]` 占位符，没有图片块渲染路径**（此前 P3-09/10 只覆盖满屏图与块背景图两条特例）；表格同理（P3-17~20 的表格块只在引擎层，flat 管线未接入）。人物卡页能显示图是因为整章纯图走了满屏图分支。

已实施图片块接入（本提交）：

1. **聚合器**（`text_aggregator.dart`）：块内唯一实质内容是 `img`/`image`（无真实文本、无强制换行）时折叠为 `tag='img'` 块节点，保留图片属性；多层容器（`div>p>img`）逐层折叠；SVG 封面链（`svg>image xlink:href`）同样命中。折叠判定必须在 `flush()`（take 清空缓冲）之前做，否则残留文本被误判为纯图（开发中发现并修复）。
2. **章节源**（`epub_chapter_source.dart`）：扫描聚合树预取章内图片原始尺寸（`ImageSizeParser`，按 URL 缓存跨章复用）；`collect` 对 img 块构造背景图 PageBlock——显示宽按 `width` 属性（%/px）解算、缺省全宽（近似 textiE1 的 `width:100%`），高按原始宽高比换算并钳制页高，`background-size: contain` 居中不变形；src 键名兼容 `xlink:href`。CSS class 尺寸（textiE1 的 100%）暂以全宽近似。
3. **fullBleedAnalysis** 兼容：纯图块折叠后不再产生 `\uFFFC` 占位文本，短路条件补扫聚合树 img 块。

回归与效果：
- 门禁全绿；table.epub 样式回归基线更新（插图从无到有，预期差异）；诸神愚戏 latency 测试从「首章 0 页」回归修复为 pages=1（130ms）。
- 新增聚合器折叠用例 5 个（div 单图/多层嵌套/svg 链/图文混合不折叠/多图不折叠）。
- 模拟器实测：**封面（SVG 链 jpg）完整渲染、章头图（4214×3229 PNG 全宽）、40% 宽分隔图、人物立绘全部显示**；正文/标题排版不受影响；此前的 D-1（图片页手势失效）与 D-2（封面空白）现象随之消失（D-1 根因未深究，观察项转真机复验）。
- 遗留：表格块未接入 flat 管线（64 章，可读性尚可降级为文字），记 P4；混合行内图仍显示 `[OBJ]` 占位，记 P4。

## 7.2 作者 CSS 接入（用户反馈「文字样式怎么没有」后追加，2026-10-25）

用户截图指出文字无样式：诸神愚戏正文全靠 class CSS（`p { text-align: justify; text-indent: 2em; line-height: 130% }`、`h2.texthE1 { text-align: center; font-weight: 900; font-family: "hh","zz" }`、30665 处 `span.fmsA3` 彩色行内文字、@font-face 内嵌字体 13 ttf + 2 otf），而 flat 管线此前只消费 UA 标签默认 + 阅读器覆盖，作者 CSS 零消费。

已实施作者 CSS 接入（本提交）：

1. **章节样式表加载**（`epub_chapter_source.dart`）：`CssParser.extractFromXhtml` 提取 `<link rel=stylesheet>` 与 `<style>`，CSS 字节按 URL 缓存跨章共享、章节样式表序列按章缓存。
2. **选择器匹配**（`_authorDeclarations`）：支持单复合选择器（`p`、`p.cls`、`.cls`），后代/子/伪类与 `@media` 规则跳过；保持文档顺序、后声明覆盖先声明（CSS 同优先级级联语义）。
3. **styleFor 叠加**：UA 默认 → 作者 CSS（标签/class 规则）合并构造，阅读器基准样式为 parent（阅读器字号仍是 em 解算基准）；引用深度边距叠加逻辑不变；块属性（class）经 collect 透传。
4. 生效属性覆盖：text-indent（首行缩进 2em）、text-align（justify 两端对齐/center 标题居中）、line-height %、margin、color、font-family（无内嵌字体时落到内置回退链）、em 字号。

回归与效果：
- 门禁全绿；新增 `author_css_test.dart` 3 用例（p 规则缩进/对齐/行距、class 规则居中且不串扰、无 link 书行为不变）。
- 模拟器实测（诸神愚戏第 4 章）：**章标题居中 + 原书配色、正文首行缩进 2em、两端对齐右缘整齐**，与原书排版一致。

遗留（P4）：行内 span 彩色文字（fmsA3 系统面板风格，需跨块 run 样式管线）；@font-face 内嵌字体在 flat 管线的加载（BookFontLoader 目前在引擎层）；表格块。

## 7.3 引擎样式能力接入：书内字体 + 行内样式区间（2026-10-25）

## 7.4 表格与分隔线接入（引擎样式能力接入完成，2026-10-25）

用户要求「将样式能力全部接入 flat 管线」。盘点 §65 清单后剩余缺口为表格（64 章）与 hr（分隔线），本轮补齐：

1. **渲染载荷**（reader_core `table_layout.dart`）：`TableCellRender`（格矩形 + 文字排版结果 + 计算样式）与 `TableRenderSpec`（格列表 + 列/行界坐标 + 表宽）；`TableGridLayout` 暴露 `columnXs/rowYs` 供绘制网格线。
2. **PageBlock 扩展**（`paginator.dart`）：可选 `table` 载荷字段——非 null 时该块是一页表格切片，layout 为空文本单行盒（高度=切片高，仅参与分页几何与进度），CFI/选区不涉及表格格文本（记录为后续增强）。
3. **渲染分支**（`page_renderer.dart` `_paintTable`）：1px 灰网格线（Reeden 630 裸表格补 border 近似）+ 逐格文字（格内顶部对齐，水平按格样式对齐——th 居中来自 UA）。
4. **章节源桥**（`epub_chapter_source.dart` `collectTable`）：聚合树 tr/td 展开（thead/tbody 自动穿透）→ 格文本抽取（嵌套块以空行拼接）→ 全宽自然宽 + 按宽测高闭包 → `TableGridMeasurer.measureGrid` 两遍列宽（首行 width 属性近似列声明、table width 属性 px/%）→ 最终列宽复测格布局 → `TablePaginator.paginateRows` 行边界切分（单行超页独占裁剪）→ 每页片一个带载荷的块。无行的异常表退化为文字流。顺带：styleFor 声明前移（表格/图片收集复用）。
5. **hr 分隔线**：空行块（1px 高）+ UA 边距 + 1px 下边框，经 `_paintBorders` 画线（此前 hr 完全消失）。

回归与效果：
- 门禁全绿（三包 + 边界）；快照 harness 为独立路径，基线不变；新增 `table_flat_test.dart` 4 用例（两列载荷/坐标、th 居中、40 行超页切分每片 ≤ 页高、hr 块）。
- 模拟器实测（诸神愚戏「游戏面板」章）：**四列表格网格线 + 单元格文字 + 跨页续行**全部正确，与装饰图、正文混排正常。

至此 §65 清单中 flat 阅读管线可承载的样式能力全部接入：文字度量链（字号/行高/字距）、对齐/缩进、行内样式区间（彩色/粗斜）、书内字体、图片（含 SVG 封面/满屏）、列表标记、引用缩进、边框/背景/圆角、表格、分隔线。仍属引擎层或后续增强：float/clear 浮动（引擎有 FloatOccupancy，flat 未接，真实书罕见）、ruby 注音、伪元素 content、表格格级 CFI/选区。

## 7.5 float/clear 浮动排版接入（引擎部件全接入完成，2026-10-25）

用户要求把引擎剩余部件（float/clear）也接入 flat 管线。实施：

1. **数据结构**（reader_core）：`PageBlock.floatSide`（FloatSide?，浮动块标记）；`PageBlockSlice.overlay/absoluteTop`（覆盖切片：不占流高、页内绝对 y）；渲染层几何构建支持覆盖切片（y 用绝对值、流游标跳过）。
2. **浮动检测**（章节源 `floatSideOf`）：三来源——内联 `style="float:…"`、历史 `align="left|right"` 属性、作者 CSS class 规则（img.side { float:left }）；浮动图钳宽 ≤45% 正文宽、高按原始比例。顺带：styleFor 补**内联 style 声明解析**（k:v 分号切分，最高优先级）——clear/color 等内联声明此前全部漏消费。
3. **浮动感知分页**（`_paginateWithFloats`，引擎 FloatOccupancy 区间模型）：浮动图不占流高、按侧登记占位、覆盖切片渲染；文本按「同占位状态」行批切段——窄幅区间重测绕排（行内样式区间不映射，记录为已知限制），区间耗尽回全宽；clear 推到该侧浮动底边并**以空白垫片切片占位**（渲染层按切片累计 y，空隙须显式承载，开发中发现）；页界浮动不跨页（整块移下页、收页清空占位）。浮动章不进 Paginator 与页索引重放（满屏章同款先例）。
4. **顺带修复真实缺陷**（`full_bleed.dart`，浮动接入用例暴露）：原始块树文本节点是 `ParsedText`（未实现 `TextBlockNode`），`analyzeFullBleed` 的 `hasVisibleText` 恒 false——「无尺寸单图 + 正文」的章节会被误判满屏、**整章正文只剩一页图**。真实书因每章多图未暴露。修复：visit 补 ParsedText 分支；新增回归用例。

回归与效果：
- 门禁全绿（三包 + 边界 + 快照基线不变）；`float_flat_test.dart` 5 用例（左浮绕排+全宽恢复、align 右浮、作者 CSS float、clear 垫片、无浮动章不受影响）+ full_bleed 补 1 用例。
- 模拟器实测（合成书《浮动排版演示》，借用真实插画）：**左侧浮动插画 + 右侧窄幅绕排**渲染正确——文字避开占位区间、间距正常、章标题全宽；clear 段从插画底边之下恢复全宽。

至此引擎样式部件与 flat 管线之间再无未接入项（ruby 注音、伪元素 content、格级 CFI/选区属新功能而非已有部件接入）。
