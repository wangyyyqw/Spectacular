# P1-27 测试报告：可取消与增量分页

> 日期：2026-10-23　执行人：Lead　任务：P1-27（2h）

## 1. 范围

- 在 `paginator.dart` 增加流式入口 `Paginator.paginate`：
  - 每产出一页 `yield`，并 `await Future<void>.delayed(Duration.zero)` 让出事件循环；
  - 每块/每行/每页检查 `CancelToken`；
  - 取消后已产出页保留，不再继续计算。
- 新增 `PagedChapterJob`：
  - `spineIndex`、`token`、`pages`、`progress`、`cancel()`、`done`；
  - `progress` 按已产出切片高度 / 总块高度计算；
  - 订阅方取消时自动触发 `cancel()`；
  - `done` 不等待暂停订阅的 close，避免 UI 暂停时无法结束。

## 3. 关键验收

| 首屏前 3 页 | `pages.take(3)` 得到 3 页，pageIndex 0/1/2 |

| 已产出页保留 | 取消后首屏页内容仍可读 |
| 流式完成 | 全量消费后 `progress == 1` |
| pageBreakBefore | 流式路径与同步路径一致 |

## 4. 已知限制

- 同 isolate 异步分页；单页计算本身超大时，只能在行/块检查点响应取消。
- `progress` 按高度比，不是精确字节比。
- 不支持暂停/恢复；取消后重新开始需要新 job。
- `PageContent` 由页生成时补 pageIndex；`done` 可能先于暂停订阅的 stream close 完成。
- 未接入 UI；P1-31/P1-32 再做虚拟页窗口与真实消费。
