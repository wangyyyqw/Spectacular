## 2. 本轮实现细节

### opacity
- `ComputedStyle.opacity`（double 0~1，不继承，初始 1；`2`/`-1` 钳制到 1/0）。
- `_withOpacity`：opacity < 1 时 `canvas.saveLayer(box.inflate(64), 白色×opacity)`，块背景/边框/文本三个绘制阶段各自包裹——层内内容互不穿透，跨几何不混层。

### text-overflow
- `CssTextOverflow { clip, ellipsis }`；未知值按 clip。
- `_needsEllipsis`：ellipsis 模式且行宽 > 块内容区宽（典型：nowrap 按无限宽测量的单行）。
- `_paintEllipsizedLine`：可见区收窄一个省略号宽 → 裁剪绘制原文本 → 右缘补「…」。**测量与分页不动**——CFI、选区、进度仍按全文；截断是纯绘制层行为（与 §63 选区命中共存）。

### box-shadow
- `CssBoxShadow { offsetX, offsetY, color }`；解析先按逗号取首个阴影段（多阴影丢弃），颜色缺省黑；`inset` 标记忽略仍按外投影；blur/spread 长度解析后丢弃。
- 绘制在块背景阶段**之前**、块裁剪**之外**（阴影可溢出块外；先影后景，背景覆盖重叠区）；仅整块落在一页时绘制（跨页切片不重复投影）。
- 修复过程发现并修正两处实现缺陷：① 阴影原画在 geometry.clip 内被裁掉；② 解析循环凑满两长度即 break 导致颜色 token 被跳过（阴影恒黑）。
