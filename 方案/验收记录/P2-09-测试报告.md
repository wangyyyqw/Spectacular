# P2-09 测试报告：首元素负 margin 钳制

> 日期：2026-10-24　执行人：Lead　任务：P2-09（3h）
> 依赖：P2-08　参考：技术方案 §60.7（负 margin 规则）；阅微 `ContainerDom.shouldClampBodyFirstElementNegativeTopMargin`

## 1. 实现

- `clampFirstElementNegativeTopMargin(marginTop, {isBodyFirstElement})`：
  - 仅当「是 body 的首个块级子元素」且 `marginTop < 0` 时钳到 0；
  - 其它情况原样返回（非首元素、正 margin、非 body 都保留原值）。
- `ColumnFlowBlock.body(...)`：页根（body）容器工厂，内部置 `clampFirstNegativeTopMargin = true`；
  - 测量后对「逸出到容器外的首块上 margin」做钳制，再与容器自身 margin 折叠；
  - 普通 `ColumnFlowBlock` 行为不变：首块负 margin 仍逸出为负值，可把整块上移。
- 与 P2-08 的嵌套逸出配合：内层不是 body，其首块负 margin 逸出成负的 `margin.top`；外层 body 再把内层这个负值钳回 0，首行不越界。

## 2. 与阅微的对照

阅微的做法（反编译 `ContainerDom`）：

- `shouldClampBodyFirstElementNegativeTopMargin(dom)`：三个条件同时成立才钳制——
  1. `dom.margin.top < 0`；
  2. `dom.element.elementSiblingIndex() == 0`（首个元素）；
  3. 父元素标签名为 `body`。
- `onLayout` 里首块：`offsetTop = min(marginTop, 0)`；命中钳制条件时 `offsetTop = 0`；非 body 容器保留负 `offsetTop`，允许首块上移。

我们采纳与不同的部分：

| 维度 | 阅微 | 我们 |
|---|---|---|
| body 判定 | 检查父元素 tag == `body` | 调用方用 `ColumnFlowBlock.body()` 标记页根 |
| 钳制时机 | `onLayout` 计算 `offsetTop` 时 | 折叠逸出 margin 时（`margin.top` 折叠前） |
| 首块正 margin | `min(marginTop, 0)` 直接丢弃 | 保留并参与折叠（P2-08 已按 CSS 处理） |
| 非 body 首块负 margin | 保留负 `offsetTop` | 保留负 `margin.top`，可上移 |
| 嵌套 | 逐层 `offsetTop` | 逐层逸出后在 body 处钳制 |

## 5. 已知限制

- body 身份靠调用方用 `ColumnFlowBlock.body()` 声明，页面构建管线尚未接入（接入时要保证根容器用 `.body()`）。
- 只有 margin，没有 padding/border，因此没有「有边框/内边距时不折叠」的判定。
- 容器自身负 margin 不会被钳制（`body` 自身 UA margin 为 0，属于理论边界情况）。
- 绝对定位与浮动的首元素不参与块流，不会被钳制（与阅微一致：它们不推进基线）。
- 竖排、跨页（P2-10 可见裁剪）尚未接入。
