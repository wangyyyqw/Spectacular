# P3-06 测试报告：字体加载失败降级

任务：字体字节损坏/格式不支持时回退系统字体并提示，不阻断阅读（P3 任务书 ｜ 预算 2h）

## 交付

- `packages/reader_core/lib/css/book_font_loader.dart` 降级语义升级
  - 告警升级为码表诊断码：格式不支持 → `E_FONT_UNSUPPORTED`（informational）；资源缺失/读取失败/注册失败/整族无 face → `E_FONT_LOAD_FAILED`（recoverable，新增码）；local 暂不可加载保持普通告警（非失败）
  - **提示只出现一次**：`_degradationSeen` 按（族, 原因）去重，同原因二次 `load()` 不再进 `result.warnings`；`degradationLog` 保留全量记录供诊断导出
  - 失败路径不阻断：单 face 失败跳过、整族失败 `engineFamily` 返回 null、消费方沿用原族名由引擎按回退链（P3-04）兜底
- 码表：新增 `E_FONT_LOAD_FAILED`，防漂移用例 45→46
- 测试：book_font_loader_test.dart 新增「字体加载失败降级」组（2 用例）

## 验收对照

| 验收项 | 结果 |
|---|---|
| 注入坏字体字节后页面仍可读 | ✅ 用例「字体不可用时页面仍可读」：资源缺失族不可用 → TextStyle 仍按原族名+回退链构造 → TextPainter 渲染出墨 |
| 提示只出现一次 | ✅ 用例「提示只出现一次」：同 faces 二次 load，第二次 `E_` 告警为空，degradationLog 全量翻倍 |
| 格式不支持提示 | ✅ woff2 → `E_FONT_UNSUPPORTED`（informational，详情页展示不弹窗，§68.6 口径） |

## 关键实现决策

1. **两级告警**：`result.warnings`（去重后，UI 消费）与 `degradationLog`（全量，诊断导出）分离——提示语义与日志语义解耦。
2. **坏字节检测时机承接 P3-02 结论**：测试环境引擎惰性解析，坏字节可能 load 或首次渲染才暴露；无论哪个阶段失败都不向上抛（P3-02 已有 catch），本任务补齐提示去重与码表。
3. UI 展示（书籍详情「部分字体无法使用」）随 M3 业务闭环接线，本任务交付码与去重语义。
