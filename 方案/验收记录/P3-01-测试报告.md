# P3-01 测试报告：解析并注册 @font-face

任务：解析字体声明、去重、生成注册任务，支持 local() 与 url()（P3 任务书 ｜ 预算 3h）

## 交付

- `packages/reader_core/lib/css/font_face.dart`
  - `CssFontSource`：`local()`/`url()` 来源项，带 `format()` 提示与不支持格式判定（woff/woff2/ttc）
  - `CssFontFace`：family、src 序列（声明顺序即回退顺序）、weight/style/display/unicode-range；`normalizedWeight`（normal→400、bold→700）、`normalizedStyle`、`dedupKey`
  - `CssFontFaceRegistry`：登记去重（同 family+字重+斜体后声明覆盖先声明；不同字重/斜体共存，供 P3-02 多字重注册）、`registrationTasks({resolveUrl})` 生成注册任务
  - `CssFontFaceExtractor`：注释/字符串感知扫描 `@font-face {…}` 块体，复用 `CssParser.parseStyleAttribute` 解析声明（csslib 的 `FontFaceDirective` 不公开声明组，故不走 csslib）
- `packages/reader_core/lib/css/parser.dart`：`CssStylesheet.fontFaces` 字段；主解析与分块恢复两条路径均提取；csslib 路径对 `FontFaceDirective` 静默跳过（不产生噪音告警）
- 测试：`packages/reader_core/test/css/font_face_test.dart`（16 用例）

## 关键实现决策

1. **去重键 = family+字重+斜体**，不是 family 单键：CSS 规范里 regular/bold 是不同 face，P3-02 同族多字重注册依赖共存语义；「重复声明覆盖」对同键声明成立。
2. **csslib 之外自建扫描器**：`FontFaceDirective` 的 `DeclarationGroup` 为内部字段，无法经公共 API 取声明；扫描器感知注释与字符串，`@font-face` 出现在注释/content 字符串里不误命中。
3. **src 多来源保持声明顺序**：真实样本大量使用「url→url→local→local」多级回退（cloverfield 的 songti 有 2 url + 4 local），消费方按序尝试。
4. **unicode-range 记录不生效**（技术方案 §68.1 口径）；woff/woff2/ttc 维持不支持口径（技术方案 §15 风险 4），仅判定并留待 P3-06 降级提示。
