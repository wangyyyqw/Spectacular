# P3-07 测试报告：实现图片资源解析与尺寸计算

任务：读取图片头拿原始尺寸，按 CSS width/height/auto 计算显示尺寸（P3 任务书 ｜ 预算 3h）

## 交付

- `packages/reader_core/lib/paint/image_size.dart`
  - `ImageSizeParser.readImageSize`：只读文件头拿原始尺寸，不解码像素（§50.3 优化 3：尺寸与位图分开缓存，排版不等解码）。支持 PNG(IHDR)/JPEG(SOF 段扫描)/GIF/BMP/WebP(VP8/VP8L/VP8X)；SVG 矢量无固定像素返回 null 走占位；空字节/损坏/零尺寸一律 null 不抛异常
  - `ImageDisplaySizing.compute`：CSS Images 3 默认尺寸算法的阅读器口径——两维都指定直接用（超容器按比例缩到贴边）；指定一维 + 有原始比例推出另一维；指定一维无原始尺寸按正方形占位（确定性优先）；全 auto 用原始尺寸、不放大、超容器缩到贴边；无任何尺寸信息按容器宽 2:1 默认占位（CSS 替换元素 300×150 的近似）
- 测试：`test/paint/image_size_test.dart`（7 用例，合成头字节覆盖 5 格式 + 四类验收）

## 验收对照

| 验收项 | 结果 |
|---|---|
| 有宽高、单边、auto、超容器四类样本尺寸正确 | ✅ 四类各一用例：80×40 直接用；宽 160 → 160×80 按比例；auto 原始尺寸 200×100 不放大；640×480 超容器缩到 266.67×200 贴边（宽高双约束） |

## 关键实现决策

1. **尺寸解析与解码分离**：本任务只出头解析与 CSS 尺寸解算；解码降采样归 P3-08（`DecodedImageCache` 已有 targetWidth 骨架）。
2. **超容器统一按比例缩到贴边**（含两维都指定的情形）：阅读器显示优先于 CSS 的溢出语义，与 §50.2「目标像素尺寸=显示宽×DPR 封顶原图宽」一致。
3. **不放大小图**：auto 时不超原始尺寸放大，避免位图糊。
