## 3. TTS 失败详情

Qualcomm 默认引擎：

```
languages=8
chinese=[zh, zh-Hans-CN, zh-Hans, zh-Hant]
zh_cn_available=true
voices=0
rates=[0.1:1, 0.5:1, 0.9:1]
speak_result=0 speak_timeout=true elapsed_ms=8018
```

设备 logcat：

```
E AndroidRuntime: NullPointerException ... TTSModuleForDSP.onSynthesizeText
W ActivityManager: Scheduling restart of crashed service
  com.qualcomm.qti.voiceai.speech/.tts.QualcommTextToSpeechService
```

改用 Google TTS（`com.google.android.tts`）后：

```
languages=81 voices=472 zh_cn_available=true
speak_result=0 speak_timeout=true
E GoogleTTSServiceImpl: Synthesis failure with error status code: -7
```

结论：该 Android 设备上两个 TTS 引擎都不能完成中文朗读回调；App 侧
`flutter_tts` 调用会超时。P6 TTS 设计需要增加引擎可用性检测、超时与降级提示，
不能假设 `speak()` 必然回调。测试已加 8 秒超时，避免挂死。
