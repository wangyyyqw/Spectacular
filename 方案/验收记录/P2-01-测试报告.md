## 1. 实现

新增 `packages/reader_core/lib/layout/line_breaker.dart`：

- `LineBreaker`：统一基于 `TextPainter` 做断行。
- 正文内容宽低于 **3em**（`fontSize × 3`）时钳制到 3em。
- 每个 `LineBreaker` 实例最多触发一次告警：
  - `code = layout.tooNarrow`
  - `requestedWidth` / `appliedWidth` / `minimumWidth`
  - 提供 `onWarning`、`tooNarrow`、`warningCount`、`lastWarning`
- `TextLayoutEngine.layout` 默认走 `LineBreaker`，可通过传入断行器观察告警。
- `text_layout.dart` 保留为兼容入口，通过 `export 'line_breaker.dart'` 继续暴露原 API。

## 4. 已知限制

- 告警默认不打印，需要调用方传入 `onWarning` 或自定义 `LineBreaker`；
  后续 UI/日志层接入时统一上报。
- 3em 下限按 CSS 字号计算，不含 `textScaleFactor`；系统字体放大时实际视觉下限会相应变大。
- 本次只做宽度钳制与统一入口，未改行切分规则；P2-02 继续处理跨页/硬换行/缩进。
- `text_layout.dart` 现在仅做 re-export，文件路径变化不影响调用方。
