# P1-01 测试报告：container.xml 解析

> 日期：2026-10-23　执行人：Lead　任务：P1-01（3h）

## 1. 范围

实现 `EpubArchive`（最小 ZIP 读取）与 `EpubContainer.parse`：读取 `META-INF/container.xml`，解析第一个 `rootfile` 的 `full-path`，支持多 rootfile 取第一个；缺失或非法时返回结构化 `EpubException`。

## 2. 环境

| 项 | 值 |
|---|---|
| Flutter / Dart | 3.47.5 / 3.13.4 |
| 依赖 | `archive` ^4.5.2、`xml` ^7.1.0 |
| 测试命令 | `cd packages/reader_core && flutter test test/epub/container_test.dart` |
| 样本库 | 本地 `test_corpus/`（不入库） |

00:00 +1: container.xml 正确定位 OPF：styles.epub

00:00 +3: 缺少 container.xml 返回结构化错误

- 多 rootfile 取第一个（`OEBPS/first.opf`）。

## 5. 已知限制

- `EpubArchive` 当前只做最小读取，CRC/OCF 校验在 P1-03 扩展。
- `readString` 统一按 UTF-8 解码，未处理 BOM 与 UTF-16；EPUB 规范要求 UTF-8/UTF-16，P1-02 读取 OPF 时再补。
- 测试依赖本地样本库；CI 无样本时自动跳过（`skip` 原因写明）。
