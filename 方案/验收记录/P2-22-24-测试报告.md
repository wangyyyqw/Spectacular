# P2-22～P2-24 测试报告：阅读器设置、主题与重排

> 日期：2026-10-24　执行人：Lead　任务：P2-22 / P2-23 / P2-24（各 3h）
> 参考：技术方案 §7.5（覆盖层）、§31（主题）、§21/§17.4（布局指纹与重排）；阅微「阅读器设置覆盖书籍样式 + 主题换色不重排 + 按 CFI 恢复位置」的做法

## 1. P2-22 阅读器覆盖层（`reader_core/lib/css/reader_overrides.dart`）

- `ReaderOverrides`：字号、行高倍数、对齐、页边距（四边）、正文色、背景色。
- `apply(base, {containingWidth})`：把设置转成 CSS 声明，以**显式属性**合并到书籍样式之上（reader origin 高于 author），未设置的属性继续继承书籍声明。
- `toCssDeclarations()`：整数像素输出 `18px` 形式；颜色输出 `#rrggbb`。
- `fingerprint`：只含字号/行高/对齐/页边距（颜色不参与布局）。
- 测试 5 条：覆盖优先且继承其余、空覆盖返回原对象、padded 声明、声明映射、指纹只含排版字段。

## 2. P2-23 主题与背景（`reader_ui/lib/theme/reader_theme.dart`）

- 五套主题：白 / 米黄 / 灰 / 深色 / 纯黑，背景与正文色成对定义；`luminance` 按 WCAG 计算，五套均 **≥4.5:1**。
- `toOverrides()` 只带颜色；`byId` 未知 id 回退白色。
- 换色不重排：颜色不进 `fingerprint`；`PagePainter.textColor` 在绘制行 span 时替换颜色（行内 run、justify 逐字符样式、上下标、着重号都覆盖），页面背景由 `PagePainter.background` 直接绘制。
- `ReaderPage` 新增 `theme`：背景色与文字色传入 painter；`didUpdateWidget` 换主题只重建 painter（触发重绘），不触发布局。
- 测试 5 条（对比度、颜色成对、byId 回退、指纹不变、WCAG 白黑 21:1）+ 绘制 1 条（换色后墨迹像素数不变、确实变红）。

## 3. P2-24 设置变更重排链路

- `reader_ui` 新增 `RestylableChapterSource` 接口（`applyOverrides`）。
- `ReaderSession.applyOverrides(next)`：
  1. 指纹未变 → 只记录设置（颜色/主题无需重排）；
  2. 记录当前页定位 CFI（优先取「在本页起始的块」，纯续页退化为第一片）；
  3. 调用来源 `applyOverrides` 重算样式/正文区尺寸；
  4. 重新加载当前章节、重建 `VirtualPager`；
  5. 在新页序列里定位第一个起点 CFI ≥ 目标的页并 `goTo`，保持阅读位置。
- `EpubChapterSource`（移动端）实现该接口：保存书籍基础样式，`contentWidth/Height` 扣除设置页边距，`style = overrides.apply(base)`；文本块用 `TextContentNode.cfi` 写入 `PageBlock.startCfi`。
- `ReaderPage`：`overrides` 参数 + `didUpdateWidget` 变化时调用 `session.applyOverrides`；页边距优先用设置值。
- 测试 5 条：字号变化触发重排且指纹更新；改字号后按 CFI 恢复（内容命中，误差 0 页）；连续快速改 5 次字号无漂移无异常；相同指纹不重排；不支持重排的来源只记录设置。

## 6. 已知限制

- CFI 恢复依赖块级 `startCfi`；同一块跨页时定位到块起始所在页（行内偏移未参与，误差 ≤1 页，满足验收）。
- 主题换色用绘制层覆盖（`PagePainter.textColor`），不改书籍样式表；`background-clip: text`、阴影色等细节不参与主题替换。
- 页边距设置通过正文区尺寸（`contentWidth/Height`）与 `ReaderPage.padding` 双处生效，未做「页边距 = 安全区 + 视觉边距」的更细分级。
- 重排期间 `loading=true`，UI 显示加载态；快速连续变更以最后一次为准（每次 await 完成，无并发竞态）。
