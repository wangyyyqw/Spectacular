## 3. 构造约定

| 项 | 约定 |
|---|---|
| spine 步 | 固定 `/6` |
| itemref 步 | `(spineIndex + 1) * 2`，与 §34.2 一致 |
| body 步 | `/4` |
| 元素路径 | 从 body 起，每层按元素子节点序号 `2*n`，有 id 则写入断言 |
| 无 fragment | 绑定到 `!/4`（body 起始） |
| 跨章 | CFI 的 itemref 步直接区分章节，无需额外字段 |

## 4. 已知限制

- 绑定器为每个目录项读取并解析所在章节 XHTML；大书全量绑定成本高，`maxEntries` 支持渐进绑定。
- 只绑定到元素起点，不构造字符偏移；字符级定位留给文本层。
- 绑定器不校验 CFI 语义（如 fragment 是否在可读区域）；失败只记录 warning。
- 目录绑定未在 `openEpub` 中自动执行，避免影响打开耗时；由调用方按需调用。
- 依赖本地样本库；CI 无样本时真实书用例跳过。
