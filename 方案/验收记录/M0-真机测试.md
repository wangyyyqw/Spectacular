## 3. 测试中发现并修复的问题

1. **日志导出崩溃**
   - 现象：日志 `export_error: Null check operator used on a null value`。
   - 根因：导出按钮的 context 在 `MaterialApp` 之上，`ScaffoldMessenger.of(context)` 失败。
   - 修复：`MaterialApp` 使用 `scaffoldMessengerKey`；新增 `export_success` 日志。真机复测分享面板正常。
2. **正文只占上半屏**
   - 现象：示例页固定按 320×480 分页，手机上下半屏空白。
   - 修复：`ReaderApp` 用 `LayoutBuilder` 把实际内容区传给 `DemoChapterSource`；
     真机按 344×699 分页，正文铺满。
3. **杀进程后进度丢失**
   - 现象：早期使用内存进度，force-stop 后回到第 1 页。
   - 修复：新增 `FileReaderProgressStore`，写入应用支持目录 `reader_progress.json`；
     真机 force-stop 后恢复到第 2 章第 1 页。
4. **正文贴边**
   - 修复：`ReaderPage` 默认 20/16 留白与 ClipRect，真机截图确认文字不贴边。
