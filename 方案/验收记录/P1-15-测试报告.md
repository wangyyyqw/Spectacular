## 4. 已知限制

- 尚未接入 CSS 样式引擎，display 仅按标签默认值判断；P2 样式解析后应改为 `ComputedStyle.display`。
- 块/行内嵌套只做一层分派：行内元素里的块级子元素不会提升，复杂脏 HTML 可能保留异常嵌套。
- 空段落只按“无文本且无子元素”判断；`<p><br></p>` 会保留，是否算空段留待 P1-16 空白规则。
- 空白文本节点仍保留；P1-16 统一空白处理。
- `table` 仅标记为 table，未拆行/单元格（P1-24）。
- `parseBlocks` 未缓存，重复调用会重复解析。
