## 3. 容错策略

| 失效类型 | 处理 |
|---|---|
| 元素步骤不存在 | 回退到同层最后一个元素，标 adjusted + warning |
| 文本节点不存在 | 回退到所在元素起点，textOffset=null |
| 字符偏移越界 | clamp 到 `[0, text.length]`，warning |
| 嵌套变化 / id 断言不匹配 | 在 body 内按 id 重新查找，重建路径 |
| itemref 与章节不匹配 | 明确失败，不跨章猜测 |
| XHTML 非法 | 返回失败结果，不抛异常 |
| CFI 是范围 | 目前按 rangeStart 解析（warning 未单独记录） |

## 4. 已知限制

- 只解析点或范围起点；范围终点容错未单独返回。
- 结构变化但索引恰好仍可解析时无法检测（未做文本哈希/上下文校验），会当作精确命中。
- 不修正数据库中的旧 CFI，只返回临时最近位置；持久化修复由上层决定。
- id 断言缺失时只能按索引回退，可能落到相邻章节内容。
- 未接入渲染/定位链路；`resolveCfi` 目前供后续文档树与进度恢复使用。
