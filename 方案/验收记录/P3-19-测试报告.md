# P3-19 测试报告：实现 colspan 支持

任务：跨列单元格参与列宽分配与绘制，命中测试按合并区域（P3 任务书 ｜ 预算 3h）

## 交付

- `packages/reader_core/lib/layout/table_layout.dart` 扩展
  - **列宽参与**（升级 P3-18 简化口径）：跨列单元格自然宽超出跨列单列自然宽之和的溢出部分，按各列自然宽比例摊给跨列——HTML 表格模型的简化实现
  - **绘制几何**：`TableGridLayout`——单元格合并区域矩形（x/y 为列/行前缀和，宽 = 跨列之和）；`cellRectAt(row, cellIndex)`
  - **命中测试**：`hitTest(point)` → (行, 行内单元格序号)；跨列单元格按合并区域整体命中（HTML colspan 语义），表外返回 null
- 测试：table_layout_test.dart 扩至 13 用例（溢出摊列、colspan=3 合并矩形、合并区域命中三向断言）

## 验收对照

| 验收项 | 结果 |
|---|---|
| colspan=2/3 渲染正确 | ✅ colspan=3：合并矩形 left=0、宽=300（三列 100×3）；单列第 3 格 left=200 |
| colspan=2/3 命中正确 | ✅ 合并区中点命中 (1,0)；单列区命中 (0,2)；表外 null |

## 关键实现决策

1. **溢出摊列而非精确 CSS 算法**：CSS Tables 3 的列宽组合优化是 NP 空间上的迭代过程；中文电子书表格实测以均匀/简单跨列为主，溢出按比例摊足以还原视觉，保留 P5 精修空间。
2. **命中与绘制同源**：两者都走 `cellRectAt` 的合并区域矩形——几何不一致会立刻被命中用例抓住。
3. rowspan（跨行）按任务书不在本期（§26.3 的 SpanningCell 续绘归 P3-20 跨页切分一并处理）。
