# P1-19 测试报告：选择器匹配与特异性

> 日期：2026-10-23　执行人：Lead　任务：P1-19（3h）

## 1. 范围

新增 `packages/reader_core/lib/css/selector.dart`：

- `SelectorParser`：用 `csslib` 解析选择器组，转成自有模型；
- 支持标签、类、ID、通配符、后代（空格）、子代（`>`）、逗号分组；
- 四元组特异性 `(inline, id, class, type)`，支持逐位比较与相等判断；
- 不支持属性、伪类/伪元素、相邻/兄弟组合符，跳过并记录 warning；
- HTML 标签匹配大小写不敏感，class/id 保持大小写敏感；
- 匹配时接收从根到父节点的 ancestor 路径，避免给解析树增加 parent 指针。

## 3. 覆盖

| 能力 | 用例 |
|---|---|
| 标签 | `p`、`div` |
| 类 | `.a`、`.a.b` |
| ID | `#p1` |
| 复合 | `p.a.b#p1`、`*.x` |
| 后代 | `div p`、`.a .x` |
| 子代 | `div > p`、`#root > p`、`div > p > span` |
| 逗号分组 | `div, span`、`#p2, #p1` |
| 通配符 | `*` |
| 特异性 | `#id`、`.a.b`、`div p`、`div.foo > p`、`*` |
| 大小写 | `DIV`、`DiV > P` |
| 未支持 | `p[title]`、`p:first-child`、`p:hover`、`div + p`、`div ~ p` → warning |

## 4. 已知限制

- 未支持属性选择器、伪类/伪元素、相邻/兄弟组合符、命名空间；遇到即跳过并记录。
- 匹配需要调用方提供 ancestors（根→父）；尚未在 `ParsedDocument` 上挂“整树批量匹配”接口。
- `inline` 特异性固定为 0；style 属性的 inline 优先级由 P1-20 层叠阶段处理。
- 只做匹配，不处理 `@media` 条件、继承、`!important` 或规则排序。
- 不支持 CSS 转义标识符、`:is()`/`:where()` 等现代语法。
