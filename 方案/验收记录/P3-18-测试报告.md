# P3-18 测试报告：实现行高与单元格回填

任务：逐行测单元格高度，行高取最大，跨列单元格宽度回填（P3 任务书 ｜ 预算 3h）

## 交付

- `packages/reader_core/lib/layout/table_layout.dart` 扩展
  - `TableCellSpec`：自然宽 + `measureHeight(width)` 高度回调（含单元格 padding 的内容高）+ colspan
  - `TableGridMeasurer.measureGrid`：列宽只统计 colspan==1 单元格自然宽（复用 P3-17 `TableMeasurer`）；行高逐行取单元格最大——跨列单元格宽度**回填为跨列之和**并按该宽测高参与取大（§62.3～§62.4），内容在回填宽度下的高度即行内占高，保证不溢出
  - colspan 越界按已知列回填兜底（不崩溃）
- 测试：table_layout_test.dart 扩至 10 用例

## 验收对照

| 验收项 | 结果 |
|---|---|
| 不同字号混排表格行高正确 | ✅ 14px 与 22px 同行：行高 = 两者最大（33） |
| 单元格内容不溢出 | ✅ 行高 ≥ 内容在最终列宽下的高度（用例显式断言） |
| 跨列宽度回填 | ✅ colspan=2 单元格按 150+150=300 测高（2 行 48），单列行 24 |

## 关键实现决策

1. **高度以回调注入**：单元格内容测量复用块测量（调用方把 TextLayout 高度包成回调），表格测量器保持纯函数、不依赖文本引擎。
2. **列宽分配只看单列单元格**：colspan 对列宽的贡献是 CSS 表格算法中最复杂的部分（列组合优化）；本阶段简化为「跨列只参与行高、不参与列宽」，中文网文实测多为均匀表格，偏差可接受——精确算法随 P3-19 colspan 用例回归再评估。
3. UA 默认值（th 加粗居中）已在 P7-03 UA 表落地；td/th 1px padding 由调用方在 measureHeight 回调内并入。
