> 日期：2026-10-24　执行人：Lead　任务：P2-16（3h）

## 1. 实现

- CSS 层（`computed_style.dart`）：
  - `wordSpacing`（继承，px/em 等长度，初始 0）；
  - `textTransform`（继承：none/uppercase/lowercase/capitalize）；
  - `verticalAlign`（不继承：baseline/sub/super/middle/top/bottom），并给出 `verticalAlignShift`：super = −0.4em、sub = +0.15em（与阅微 BaselineShift 同值），其余 0。
- 测量层（`line_breaker.dart`）：
  - `textStyleFor` 接入 `wordSpacing`；`letter-spacing` 沿用既有接线；
  - `text-transform` 在 `_layoutRaw` 测量前应用（大写/小写/按空白词首大写），`TextLayoutResult.text` 即变换后文本，绘制直接复用；
  - `StyledRun` 增加 `baselineShift`（逻辑像素，正值向下），`_normalizeRuns`/`_sliceRuns`/脚本回退合并都保留该值；行高与行宽不因偏移改变。
- 绘制层（`page_renderer.dart`）：
  - 无偏移的行仍一次整行绘制（像素行为不变）；
  - 有偏移的行按样式区间切段：先用整行 `TextPainter` 的 `getBoxesForSelection` 取段起点 x，再逐段按 `y + baselineShift` 绘制；
  - 裁剪矩形按本页最大上/下偏移放宽，避免首行上标被切片裁剪切掉。

## 2. 与阅微的对照

| 维度 | 阅微 | 我们 |
|---|---|---|
| letter-spacing | 转 em 写进 `SpanStyle` | px 直接进 `TextStyle`（与既有布局口径一致） |
| word-spacing | 无该属性 | 新增（`TextStyle.wordSpacing`） |
| text-transform | 无该属性 | 新增（测量前变换文本） |
| vertical-align: sub/super | `BaselineShift.Subscript`（−0.15）/`0.4` | `verticalAlignShift` = +0.15em / −0.4em，`StyledRun.baselineShift` 驱动绘制 |
| vertical-align: middle | `LineHeightStyle` center + trimBoth | 解析保留，绘制暂按 baseline（行高样式另做） |
| 偏移参与测量 | Compose 排版内建基线偏移 | 不参与行高（只移动绘制），裁剪放宽兜底 |

## 5. 已知限制

- 行内元素的 CSS 样式尚未逐节点下发：`vertical-align` 目前由调用方在 `StyledRun` 上设置 `baselineShift`（能力已具备，等内联样式接入）。
- `text-transform` 会改变 `layout.text` 与原文的偏移（如 ß→SS），CFI/选区的映射需要后续用变换表换算；`capitalize` 按空白分词，标点边界是近似。
- 上下标偏移不进入行高测量：贴近行顶/行底时可能压到相邻行（裁剪已放宽，不丢墨迹）。
- have-justify 行遇到偏移段时该行退回逐段绘制，会丢掉 justify 的间隙字距。
- `middle/top/bottom` 只解析，绘制按 baseline；表格/行内盒的垂直对齐留给后续任务。
