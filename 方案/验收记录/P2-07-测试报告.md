# P2-07 测试报告：约束分派顺序

> 日期：2026-10-24　执行人：Lead　任务：P2-07（3h）
> 依赖：P2-06　参考：技术方案 §60.2（分派顺序）、§60.3（基线推进）、§60.5（浮动首选宽）；阅微 `BoxConstraints.compute` / `ContainerDom.onMeasure`

## 1. 实现

- `ComputedStyle` 增加三个不继承字段（§60.2 的判定输入）：
  - `position`：`static/relative/absolute/fixed/sticky`，初始 `static`；
  - `cssFloat`：`none/left/right`（`inline-start/inline-end` 分别映射左右），初始 `none`；
  - `display`：`block/inline/inline-block/table/table-row/table-cell/flex/list-item/none`，初始 `block`，未知值兜底为 `block`。
- `lib/layout/block_flow.dart` 增加分派层：
  - `FlowBranch`：`absolute / float / table / inline / block / none`；
  - `resolveFlowBranch(style)`：按 §60.2 顺序判定——绝对/固定定位 → 浮动 → 表格 → `display:none` → 行内 → 块级兜底；
  - 分支盒：
    - `AbsoluteFlowBlock`：按容器约束独立测量，`isOutOfFlow = true`；
    - `FloatFlowBlock`：按可用宽做 fit-content（窄内容不换行、宽内容在可用宽处折行），`isOutOfFlow = true`；
    - `TableFlowBlock`：占流，宽度对齐内容区（单元格布局留 P3-18）；
    - `InlineFlowBlock`：宽高取子节点最大值，不求和（§60.4）；
    - `HiddenFlowBlock`：`display:none` 不测量子节点，尺寸为零；
  - `createFlowBox(style, text/children)`：按分支包一层对应盒，返回的分支与判定一致；
  - `ColumnFlowBlock`：脱离流的子块照常测量，但不推进块流高度（§60.3），宽度仍参与最大值。

## 2. 与阅微的对照

阅微的分派事实（反编译）：

- `BoxConstraints.compute(ContainerDom)`：`position.absolute` 直接 `createContainerConstraints(computedWidth)`，不参与流；否则按 `boundaryWidth` 扣减宽度、裁掉被占用区域，`width` 固定时覆盖内容宽。
- 另有 `compute(TableDom)` 独立分支（宽度 = 内容宽 − 边界，固定宽覆盖）。
- `prepare(dom)`：`clear` 有效时清空约束；`float` 有效时取 `min(内容宽, max-width)` 且至少 1px 做 shrink-to-fit。
- `ContainerDom.onLayout` 按节点类型分派：`ContainerDom` → `onContainerLayout`（含 `prepare` 收缩）、`ContentDom` → `onContentLayout`（内容测量可能派生占位节点）、`TableDom` → `onLayout(baseline.compute(table))`、`PlaceholderDom` → 只登记；浮动子节点额外走 `computeWithFloat` 占位。
- `onMeasure` 收尾：`if (float 有效 || position.absolute) return;` 否则 `baseline += 自身高度`；容器存在浮动子节点且有 `clear` 子节点时补 `padding.bottom`。
- `isImageGallery` 时宽高取子节点最大值（与 §60.4 同口径）。

我们采纳与不同的部分：

| 维度 | 阅微 | 我们 |
|---|---|---|
| 分派依据 | 元素类（TableDom）+ style（position/float/display） | 纯 style（display/position/float），表格由 display 判定 |
| 绝对定位约束 | 自身 computed width 新建容器约束 | 暂用容器约束（`width` 尚未解析） |
| 浮动 | fit-content 宽度 + `BoxOccupied` 占位参与后续行盒 | 只做 fit-content 尺寸与脱离流标记，占位/绕排留后续任务 |
| 基线推进 | `onMeasure` 末尾按 float/absolute 提前 return | `ColumnFlowBlock` 跳过脱离流子块高度 |
| 表格 | 独立 `compute` + `TableDom` 布局 | 占流近似，单元格布局留 P3-18 |
| 不显示 | `display:none` 无节点 | `HiddenFlowBlock` 不测量子节点 |
| 竖排 | `writing-mode` 分支 | 未接入，统一按水平（P5） |
