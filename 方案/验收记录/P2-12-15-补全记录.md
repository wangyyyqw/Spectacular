## 2. 补了什么（对照阅微）

### 2.1 按字形覆盖的字体族分段（对应阅微 `ContentDom.applyScriptFontFallback/buildScriptRanges`）

- 阅微：逐字符按 `font-family` 列表顺序找第一个「内嵌且有字形」的族（`FontProvider.embeddedHasGlyph`），连续同族合并成 `SpanStyle` range 覆盖原文。
- 我们：新增 `ScriptFontRun` + `buildScriptFontRuns(text, families, {hasGlyph})`，逐码元取首个命中族、连续同族合并、无命中的字符不产区间；`LineBreaker/TextLayoutEngine.layout` 增加可选 `hasGlyph`，把族分段叠加进 `layout.runs`（行内样式优先、只改 font-family，其余字段继承；升序不重叠），画家沿用 runs 建 span 即生效。
- 差异：字形覆盖要由上层字体注册表提供，当前 `hasGlyph == null` 时完全走原路径（生产链路暂未接线，能力对直接调用方可用）。

### 2.2 background-image 平铺（对应阅微 `CSSBackgroundNode.draw()`）

- 阅微：先画背景色，再逐层画 image（position/size/repeat/clip/origin/attachment/radius 裁剪，支持 data/file/gradient）。
- 我们：`paintTiledBackgroundImage(canvas, image, bounds)` 按 CSS 默认（左上、原生尺寸、repeat）平铺并裁剪到块盒子；`PagePainter` 增加可选 `imageLookup`，背景色之后画图，圆角时用 `clipRRect`。解码/缓存留给调用方资源层，绘制过程无 IO。
- 差异：`background-size/position/repeat/clip`、多层图与 gradient 未实现；`reader_ui` 生产调用点尚未传入 `imageLookup`。

### 2.3 分页/命中几何接盒模型内缩（对应阅微 `boundaryWidth` 进约束、`drawFixHeight` 进绘制）

- 阅微：父约束先扣 `boundaryWidth`（border+padding+margin），绘制按 `drawFixHeight` 裁；分页与绘制共用同一套几何。
- 我们：`PageBlock` 增加 `topInset/bottomInset/leftInset` 与 `PageBlock.styled`（按 `BoxModel` 折算）；`PageBlockSlice` 增加 `leadingExtent/trailingExtent/leftInset` 且 `height` 含首尾额外高度；分页器把段前/段后间距与首尾内缩计入可用高（放不下时退一行），`totalHeight` 改用边框盒高；`hitTest` 跳过内缩区；`PagePainter` 不再自己算内缩，全部读切片几何（已消除绘制与分页各算一套的坐标差）。
- 章节源 `EpubChapterSource` 改用 `PageBlock.styled(containingWidth: contentWidth)`。

- 字体分段按 UTF-16 code unit 迭代（与阅微 Java char 一致），代理对未特殊处理。
