## 交付

- `packages/reader_core/lib/epub/importer.dart`（新）
  - `EpubReadability.grade`：L0～L4 纯函数判定，输入直接消费警告串诊断码（P7-05 码表）+ 导入期检测计数；L3 = 容器/OPF 回退拼装或 spine 过半失效，L2 = spine 项缺失/资源缺失/目录退化，L1 = 引用级修复（小写/文件名/media-type 兜底 + 识别）
  - `buildFallbackPackage`：**无 OPF 的 L3 兜底**——按文件名排序把 XHTML 拼成最小 spine（§55.1「比直接拒绝有价值」），零 manifest 时才维持拒绝
  - `probeImport`：导入期检测——spine 项存在性 + manifest 图片/字体可解性（resolve 兜底命中计 repaired，sniffResolve 命中计 repaired，全失计 missing）
- `epub_document.dart`：openEpub 重构出 `_finishOpen` 收尾段——检测 → 码化警告（E_SPINE_MISSING/E_RESOURCE_MISSING/E_RESOURCE_REPAIRED）→ 分级写 `ImportReport.readabilityLevel`；全部拒绝路径显式 L4；`ResourceIndex.fallbackHits` 计数兜底命中（L1「已自动修复 N 处」的来源）
- 分级落库与 UI 提示（BookEntry.readabilityLevel + 书架角标）随 P3-27 拒绝路径一并接线（同一 app 层改动）
- 测试：`test/epub/readability_test.dart`（6 用例：§55.4 样本 A→L1、B→L2、C→L3 可读两章、D→L4、完整书→L0、grader 纯函数）
