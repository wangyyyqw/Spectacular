# P3-09 测试报告：实现图片绘制与占位

任务：按页绘制图片，未解码完成时绘制占位块，不阻塞分页（P3 任务书 ｜ 预算 3h）

## 交付

- `packages/reader_core/lib/paint/image_paint.dart`
  - `ImageBlockPainter.paint`：缓存命中 → `drawImageRect` 等比铺满目标矩形（显示尺寸布局期已由 P3-07 算好）；未命中 → 画占位（#E8E8E8 圆角底 + #BDBDBD 描边）并 fire-and-forget 触发 `cache.load`——**解码不进绘制路径**（Reeden 540 号：翻页帧预算内不做解码 IO），宿主监听 `revision` 重绘替换
  - `ImagePaintMetrics`：占位帧数 / 成图数 / 替换耗时分开埋点（540 号口径）
  - `ImagePageDetector.isFullBleedPage`：满屏判定前置工具（单图无正文 → 满屏；双图/含正文普通路径，§8.6），供 P3-10 接入章节源
  - `ImageFit.contain`：绘制期等比居中兜底
- 字节缺失/解码失败：占位长期保留（§50.2 失败降级），不抛异常
- 测试：`test/paint/image_paint_test.dart`（4 用例，像素级验证占位底色与替换后成图颜色）

## 验收对照

| 验收项 | 结果 |
|---|---|
| 翻到未解码页先显示占位 | ✅ 像素断言：首帧未命中画占位底色 0xE8E8E8 |
| 200ms 内替换为图片 | ✅ 同帧异步触发解码，下一帧命中画图（测试中替换即成）；真机替换耗时埋点走 `ImagePaintMetrics`，P3-30 记录实测值 |
| 布局不跳动 | ✅ 布局只消费 P3-07/P3-08 的尺寸缓存（头解析结果），占位与成图用同一显示矩形 |
| 不阻塞分页 | ✅ 解码在 `cache.load` 异步路径，绘制同步路径只做 `lookup` |

## 关键实现决策

1. **绘制层与布局层解耦**：`ImageBlockPainter` 只吃矩形 + url，不感知块模型；img 作为块进入分页流（块模型扩展）随 P3-10 满屏路径落地——届时章节源对满屏章走专用页构建，普通内联图维持 U+FFFC 占位字形，块模型不动。
2. `ImagePageDetector` 放本文件而非 layout：判定输入（图数/正文标记）来自聚合层，满屏页构建属章节源逻辑。
