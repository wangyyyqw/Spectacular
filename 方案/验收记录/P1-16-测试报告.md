# P1-16 测试报告：文本聚合与空白处理

> 日期：2026-10-23　执行人：Lead　任务：P1-16（3h）

## 1. 范围

新增 `packages/reader_core/lib/parser/text_aggregator.dart`：

- 相邻文本节点与行内元素（span/b/i/...）合并为同一个 `TextContentNode`；
- 块级子元素切断聚合；
- `white-space: normal` 规则：连续空格/换行/制表符折叠为一个空格，块首尾去空白；
- `&nbsp;`（U+00A0）与全角空格（U+3000）保留；
- `<pre>` 保留换行与制表符；
- `<br>` 转强制换行标记；
- 行内图片占一个 `\uFFFC` 占位字符；
- 生成 `runs`（样式区间占位）与 `hardBreaks`；
- `EpubDocumentImpl.aggregateText(spineIndex)` 接入。

## 4. 已知限制

- 只实现 `white-space: normal` 与 `<pre>` 的保留；`nowrap` / `pre-wrap` / `pre-line` / `break-spaces` 等值待样式引擎接入。
- 块级判断仍按标签默认值（P1-15），尚未读 CSS `display` / `white-space`。
- `runs` 只记录范围，不带样式；P1-21 后填充。
- 行内图片只插入 `\uFFFC` 占位，未记录资源 href 与尺寸；P3 图片管线处理。
- `<br>` 只记录 hardBreaks，不处理连续 br 产生的空行去留；P1-22 行布局时决定。
- 未处理 `text-indent`、段首全角空格保留标记；P1-21/P2 处理。
