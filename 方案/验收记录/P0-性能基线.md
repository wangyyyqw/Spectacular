# P0 性能基线（文本测量与分页模拟）

> 任务：P0-14。日期：2026-10-22。执行人：Lead。

## 1. 目的

在尚无分页器实现时，用 `TextPainter` 级别的段落测量模拟“1 万字章节 → 页”的流程，记录冷/热耗时，作为 M1 分页性能优化的对照基线。

## 2. 环境

| 项 | 值 |
|---|---|
| 设备 | MacBook（macOS 26.7.1，arm64 / Rosetta） |
| Flutter / Dart | 3.47.5 stable / 3.13.4 |
| 构建模式 | `flutter test`（JIT，非 release） |
| 字体 | 引擎默认字体 |
| 样本 | 100 段 × 100 中文字，共 10,000 字；字号 16，行高 1.6，内容宽 360 |
| 方法 | 每段 `ParagraphBuilder.build()` + `layout()`；按高度累计模拟分页；3 次取中位数 |

## 3. 结果

| 指标 | 数值 |
|---|---|
| 段落数 | 100 |
| 模拟页数 | 25 |
| 冷路径总耗时（构建 + 布局 + 分页） | 4.0 ms |
| 冷路径单页均摊 | 0.16 ms |
| 缓存复用（仅分页统计） | 0.02 ms |

> 冷路径 4ms 低于技术方案 §11.2 的“单页构建 <8ms”预算。该数字不含真实渲染、图片、浮动与样式计算，不能直接当作 M1 达标证据，只作为回归对照。

## 4. 复现

```bash
bash tool/bench/run_bench.sh
```

期望输出：

```
P0-14 chars=10000 paragraphs=100 pages=25 cold_ms=4.0 warm_ms=0.02 per_page_cold_ms=0.16
```

## 5. 限制与后续

- `flutter test` 是 JIT 模式，与真机 release/AOT 数据不可比；M1 的性能验收（P2-26）必须在真机 profile 模式复测。
- 文本为重复构造的合成段落，未覆盖注释、ruby、图片与浮动。
- 本基线只冻结“测量方法 + 数量级”，不承诺绝对值稳定；每次优化按同一脚本对比。
