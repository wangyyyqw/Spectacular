# P1-18 补充验证：下载目录 EPUB 的 CSS 全量解析

> 日期：2026-10-23　范围：`~/Downloads` 下全部 19 个 EPUB　执行人：Lead

## 1. 方法

1. `unzip -Z1 <book>` 列出每个 EPUB 的 CSS 条目；
2. `unzip -p <book> <entry> </dev/null` 逐文件提取（避免把多个 CSS 拼在一起造成边界误报）；
3. 用 `CssParser.parse` 解析，统计规则、告警、异常；
4. 对告警分类：csslib 语法错误、跳过的 `@` 指令、空值声明等。

## 3. 发现的问题

部分 EPUB 的 CSS 存在**早期语法错误**，`csslib` 默认会截断后续内容：

| 书 | 问题 | 修复前规则 | 修复后规则 |
|---|---|---:|---:|
| 诸神愚戏 典藏版 | CSS 多一个 `}`，第 74 行后内容丢失 | 226 | 3,310 |
| 克拉夫特异态学笔记 | 同上（同一套多看 CSS） | 7 | 1,314 |
| mj-001/002/003 | `margin: 1em 0em 1.em 0em` 非法值，第 890 行后截断 | 99 | 296～297 |

修复：在 `CssParser` 增加按顶层花括号分块恢复（`_parseRecovered`）。检测到 csslib 语法错误时，逐块重新解析；若恢复出的规则更多则采用恢复结果，同时保留原语法告警。

- 19 本书合计：**20,209 → 25,192 条规则**（+4,983）。
- 其他 14 本书规则数不变。
- 仍然 **0 解析异常**；语法错误只记录 warning，不向上抛。

## 5. 限制

- `@import` 不递归采集；只验证被 EPUB 直接引用的 CSS 文件。
- `@font-face`/`@page`/`@charset` 按设计跳过并记录，不是解析失败。
- 非 UTF-8 CSS 以 `allowMalformed` 解码，中文可能出现替换字符；本次规则解析未受影响。
- 分块恢复只在检测到 csslib 语法错误时启用；被截断的那一条规则本身仍可能丢失。
- 该验证依赖本机下载目录，不进入 CI。
