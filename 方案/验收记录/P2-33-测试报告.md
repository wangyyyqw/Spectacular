## 3. 使用方式

```bash
cd packages/reader_core
STYLE_REGRESSION_REPORT=1 flutter test test/snapshot/style_regression_test.dart  # 对照并生成 M1-样式回归.md
STYLE_REGRESSION_UPDATE=1 flutter test test/snapshot/style_regression_test.dart  # 有意变更后重建基线
```

样本库 `test_corpus/` 不入库，CI 无样本时打印 `SKIP` 直接通过；基线 JSON 已入库，本地/CI 均可复核。

## 5. 已知限制

- 样本只覆盖 5 本（basic/styles/table/toc-ncx/cjk-vertical），技术方案 §45.3 的 15 组尚未全接入；图文混排、ruby、内嵌字体等组在 P3 补齐后追加。
- `cjk-vertical.epub` 当前按横排渲染（writing-mode 未实现），其基线是「去竖排」的预期结果。
- 差异归因目前是人工流程：测试失败 → 查看报告页摘要 → 确认是预期变更则 `STYLE_REGRESSION_UPDATE=1` 重建基线；没有自动「预期变更白名单」机制。
- 快照用页面布局哈希（不含光栅化像素），跨平台稳定；`inkPixels` 仅作差异参考。
