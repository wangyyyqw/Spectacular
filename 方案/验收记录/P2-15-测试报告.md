## 1. 实现

- CSS 层（`computed_style.dart`）：
  - 新增 `CssVisibility {visible, hidden, collapse}` 与 `CssWhiteSpace {normal, nowrap, pre, preWrap, preLine}`，两者都是**继承属性**，非法值回退父值/初始值；
  - `display` 沿用 P2-07 的 `CssDisplay`（block/inline/inline-block/table/…/none）与 `resolveFlowBranch` 分派。
- `display: none` 不占位：
  - 分页器跳过 `style.display == none` 的 `PageBlock`（不推进已用高度、不产生切片）；
  - 更早的 `BlockBuilder` 已把 `script/style` 之类 no-display 标签丢弃；块测量层的 `HiddenFlowBlock`（P2-07）尺寸为零、不测子节点。
- `visibility`：
  - `PagePainter` 对 `hidden`/`collapse` 跳过背景、边框与文字绘制，但行位置与分页高度照旧 → 隐藏不塌陷。
- `white-space`：
  - 聚合层 `TextAggregator.aggregate(document, whiteSpace:)`：
    - normal/nowrap：连续空白折叠成一个空格，换行折叠为空格；
    - pre / pre-wrap：保留空格与换行，换行记入 `hardBreaks`；
    - pre-line：空格折叠、换行保留；
    - `<pre>` 标签始终按 `pre` 处理并向下传播；
  - 断行层 `LineBreaker.layout`：nowrap/pre 按无限宽测量（不软换行、硬换行仍生效），pre-wrap/pre-line 正常软换行；
  - 接线：`EpubDocumentImpl.aggregateText(spineIndex, whiteSpace:)`，`EpubChapterSource` 传入 `style.whiteSpace`。

## 5. 已知限制

- 逐块样式尚未从 CSS 级联下发（`EpubChapterSource` 当前用单一 `ComputedStyle`），所以 `white-space`/`visibility` 目前按整章样式生效；逐块生效要等样式树/逐块级联任务。
- `visibility: collapse` 按 `hidden` 处理（表格行/列的折叠未实现）。
- `display: inline` / `inline-block` 仍只有 `FlowBranch` 分派（P2-07），没有真实并排换行排版。
- `pre` 保留制表符与多空格时，制表宽度按字体度量、参与 text-align/justify 的细节未做；`break-spaces` 归入 pre-wrap。
- 分页几何未接 padding/border inset（P2-14 遗留），带内边距的块在分页与绘制之间仍有高度差。
