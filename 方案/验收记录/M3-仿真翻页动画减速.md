## 2. 变更

- 仿真模式的收尾动画由固定 300ms 调整为 420ms，延长约 40%。
- 拖动阶段仍直接跟手，回弹/完成判定、完成阈值、角部边界约束、中部直立卷面均未改。
- 目标页仍在收尾动画结束后才提交；没有新增依赖、公共 API 或正文布局改动。

最终包测试《游戏入侵》“世界万族”，所有坐标使用 Android Use 的 720×1600 坐标系。
