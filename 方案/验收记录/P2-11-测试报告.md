# P2-11 测试报告：块测量不变量

> 日期：2026-10-24　执行人：Lead　任务：P2-11（3h）
> 依赖：P2-10　参考：技术方案 §60.10（不变量清单）；阅微 `ContainerDom.calculateSize` / `onMeasure` / `drawFixHeight`

## 1. 实现

- 产出 `packages/reader_core/test/layout/block_invariant_test.dart`（7 条），把 §60.10 的不变量落成断言：
  - `_checkInvariants(node)` 递归检查：尺寸有限非负、宽度不越约束、行右缘不越行宽、子块顶边/底边/宽度不越父块、非负 margin 下顶位单调不减；
  - `_checkPagination(blocks, pageHeight)` 检查：页内容高不越界（2px 容差）、切片至少一行、行号不越块、切片高度 = 可见行高之和、切片高度 ≤ 块高度、每块所有行恰好被覆盖一次且顺序连续；
  - `_randomTree` 生成可复现随机块树（3 个种子 × 8 棵，深度 0–3，字号 12/16/20/24，display inline/table，position absolute，float left/right，justify，宽约束 80–320）。
- 把「超负 margin 允许上移重叠」与「单行高于整页强制放行」写成显式例外，避免不变量测试变成假阳性。

## 2. 与阅微的对照

阅微没有独立的断言函数，不变量由字段与流程保证（反编译）：

- `calculateSize` 合成 `contentSize`，宽度分支按 `min/max/fit-content` 与约束对齐 → §60.10#1 的宽度不越界。
- `boundaryWidth = border + content + padding + margin + direction + viewport` → §60.10#2。
- `onMeasure` 收尾 `if (float 有效 || position.absolute) return;` 才 `baseline += 自身高度`，所以浮动/绝对定位不参与基线 → §60.10#4。
- 跨页时 `drawFixHeight < drawRealHeight`，绘制按 `drawFixHeight` 裁剪 → §60.10#5。

我们的对应：

| §60.10 不变量 | 我们的断言 |
|---|---|
| 1 宽度不越约束 | 随机树 / 极端样本逐节点断言 `size.width <= constraints.maxWidth`；行层面断言 `offsetX + width + justifyExtra <= 行宽` |
| 2 boundary 合成 | **未覆盖**：暂无 padding/border，等 P3 边框任务 |
| 3 子块不越父块 | 非负 margin 样本断言 `top >= 0`、`top + height <= 父内容高`、`child.width <= 父宽`；负 margin 样本只保留下界约束 |
| 4 基线单调 | 非负 margin 样本断言 `childTops` 单调不减；负 margin 允许回退（CSS 语义） |
| 5 drawFixHeight ≤ drawRealHeight | 断言 `slice.height <= block.height` |

不写进库内运行期 `assert`：热路径每帧调用，断言开销与关闭策略都不划算，测试层保证即可（与阅微把不变量落在字段计算里的做法一致）。

## 5. 已知限制

- §60.10#2 的 boundary 合成（content + padding + border + margin）未覆盖：目前只有 margin，padding/border 随 P3 边框任务接入。
- 超负 margin（超过前一块高度）会把子块顶到父块上边之外，包含不变量按 CSS 语义不适用，测试中作为显式例外单列。
- 页高不越界有 2px 容差与「单行超页强制放行」两个例外，都写成了独立用例而不是静默放宽。
- 随机样本是固定种子而非 property-based 框架生成；样本维度（字号/display/浮动/对齐）覆盖面已记录，后续可扩。
- 竖排/RTL 与跨页浮动、绝对定位未接入。
