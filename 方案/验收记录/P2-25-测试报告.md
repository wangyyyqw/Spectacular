## 2. 框架设计

- **样本**：内存构建 3 章 EPUB（每章 8 段固定中文，字句不随版本变化），用 `buildZip` 生成，避免依赖被 gitignore 的 `test_corpus/`，CI 可复现。
- **管线**：`openEpub` → `aggregateText` → `TextLayoutEngine.layout` → `Paginator.measureChapter` → 逐页生成记录：
  - `layoutHash`：该页可见文本 + 每行起点/宽度/行高（×100 取整）→ SHA-256（跨平台稳定）；
  - `inkPixels`：按 DPR 渲染后的非白像素数（参考值，不参与断言，避免光栅化平台差异）；
  - `lineCount` / `textLength`。
- **整书哈希**：`SHA-256(spec + 每页 layoutHash/lineCount/textLength)`，顺序敏感。
- **基线与更新**：基线 JSON 入库；`SNAPSHOT_UPDATE=1 flutter test test/snapshot/page_snapshot_test.dart` 重建。
- **差异报告**：`describeFirstDifference` 返回「首个不同页号 + 版式哈希 + 像素差（当前/基线墨迹像素数）」，页数变化单独报告；有独立单测覆盖失败路径文案。

## 5. 已知限制

- `inkPixels` 是光栅化结果，跨平台可能有个位数差异，因此不参与 `bookHash` 与断言，只在差异报告里给出参考。
- 基线随排版变更需手动更新（`SNAPSHOT_UPDATE=1`），更新后的 diff 应在验收记录中审阅页数与像素差。
- 样本是合成 EPUB，覆盖正文分页与中文排版，不含真实书的复杂 CSS/图片；真实书快照可在后续用本地样本库做可选扩展。
- 快照测试渲染 6 页（640×1200 像素图），本地/CI 增加约 2 秒。
