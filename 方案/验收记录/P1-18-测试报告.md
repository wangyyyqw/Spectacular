## 3. 与阅微的对照

阅微的 `StyleSheetsProvider` 没有用 CSS 语法解析器，而是：

- 正则 `(?s)/\*.*?\*/` 去注释；
- 正则匹配 `@import` 并递归读取文件，再把 `@import` 从文本里删掉；
- 正则 `(?s).+?(?:\s*,\s*.+?)*\s*\{[\s\S]*?\}` 切规则块；
- 不支持嵌套 `@media`、字符串中的 `/*`/`{}` 容易误判，`@import` 只能处理简单形式。

本实现改用官方 `csslib` AST：

- 注释、字符串、嵌套 `@media` 由解析器处理；
- `@media` 展平并保留条件；
- 非法声明不拖垮整张表，逐条跳过并记录；
- `@import` 保留为 URL + media，由调用方按资源索引加载。

参考：阅微 `org/epub/css/StyleSheetsProvider.java`；Dart `csslib`（https://pub.dev/packages/csslib ）；CSS Syntax 3（https://www.w3.org/TR/css-syntax-3/ ）。

## 4. 已知限制

- 只负责“解析成规则”，选择器匹配、特异性、层叠与继承在 P1-19/P1-20。
- `@font-face` / `@page` / `@supports` 等指令暂跳过并记录 warning；字体规则在 P2 字体层处理。
- `@media` 只保留条件字符串，不做设备求值。
- `@import` 不自动加载；调用方需结合资源索引递归读取，避免解析器依赖 IO。
- 不处理 CSS 变量 `var()`、预处理器语法、简写展开。
- 非法属性名/空值由本层过滤；未知但语法合法的属性保留（后续 Cascade 决定是否忽略）。
