# P1-21 测试报告：ComputedStyle 最小字段集与单位换算

> 日期：2026-10-23　执行人：Lead　任务：P1-21（3h）

## 1. 范围

完善 `packages/reader_core/lib/css/computed_style.dart`，并让 `Cascade` 传入父样式、根字号与容器宽度：

- 类型化最小字段：
  - `fontSize`（逻辑像素）
  - `lineHeight`（逻辑像素）/ `lineHeightFactor`
  - `color`（`dart:ui Color`）
  - `fontWeight`（100–900）
  - `italic`
  - `fontFamily`（首选家族）
  - `textAlign`（自有 `CssTextAlign` 枚举）
  - `margin`（自有 `CssEdges`）
- 默认值：16px 字号、24px 行高（1.5 倍）、黑色、400、非斜体、start、margin 0。
- 单位换算：px、em（相对当前/父字号）、rem（根字号）、%（字号相对父、行高相对自身、margin 相对容器宽）、pt（96/72），另补 pc/in/cm/mm。
- 颜色：`#rgb`、`#rrggbb`、`rgb()`/`rgba()`、常用命名色、`transparent`。
- 继承：显式属性集合 + 父样式字段；未设置字段取父值，无父值时取初始值。

## 4. 已知限制

- `line-height` 的数值倍数在继承时按父级像素值传递，未保留“倍数随子字号重算”的语义；后续行布局需要时再补。
- 百分比 margin 依赖调用方传入 `containingWidth`，未传时为 0。
- 只实现 `margin` 简写/四边；padding/border/width 等 P2 再做。
- 字体族只取第一个，未建 fallback 链。
- 颜色支持有限；8 位 hex 当前按 ARGB 解析，未按 CSS 的 RRGGBBAA。
- 未处理 CSS 变量、`calc()`、`currentColor`、系统色。
- `ComputedStyle` 仍保留原始 `values` 字符串表，供层叠调试和后续属性扩展。
