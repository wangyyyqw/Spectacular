# P2-10 测试报告：跨页可见裁剪

> 日期：2026-10-24　执行人：Lead　任务：P2-10（3h）
> 依赖：P2-06　参考：技术方案 §60.8（可见裁剪）；阅微 `ContainerDom.getVisibleMargin/getVisiblePadding/getDrawableChildren/drawFixHeight`

## 1. 实现

- `PageBlockSlice` 增加可见性描述：
  - `continuesBefore` / `continuesAfter`：本页切片是否在块中部开始/结束；
  - `clipRect(top, width)`：切片在页面坐标系里的裁剪矩形，绘制与命中共用同一套几何。
- `PageContent.hitTest(offset, {contentWidth})`：返回 `PageHit`（切片序号、切片、块内行号、行框）；只在本页可见的切片与行内命中，内容区之外返回 null，跨页块属于别页的行不会被命中。
- `PagePainter` 逐切片裁剪：`save → clipRect(切片矩形) → 逐行绘制 → restore`。字号/行高浮点误差、抗锯齿溢出都限制在切片矩形内，不会画到下一块或下一页。
- 段前/段后间距只在块真正开始（`startLine == 0`）或结束（`endLine == lineCount`）时叠加，续页不重复。

## 2. 与阅微的对照

阅微的做法（反编译 `ContainerDom`）：

- 字段：`offsetTop / offsetBottom`、`drawFixHeight / drawRealHeight`、`isPageTopElement`；`drawFixHeight < drawRealHeight` 即表示该块跨页。
- `getDrawableChildren(range)`：只画落在本页 CFI `range` 内的子节点，范围外的子节点不参与绘制——这就是「下一页无残留」的来源。
- `getVisibleMargin(range)`：节点起点正好落在本页起点时，四边 margin 归零（本页顶部已有页面留白，不再重复叠加）；`getVisiblePadding` 在页尾截断时把 `bottom` 置零。
- `getVisibleOffsetY(range)`：节点从本页开始则偏移 0；否则按浮动/`offsetTop` 取可见偏移。
- 绘制用 `drawRect = (offsetTop, offsetTop + drawFixHeight)` 裁剪。

我们采纳与不同的部分：

| 维度 | 阅微 | 我们 |
|---|---|---|
| 可见范围 | CFI range + 子节点筛选 | 行切片（`startLine..endLine`） |
| 裁剪几何 | `drawRect`（块内偏移 + 绘制高度） | `PageBlockSlice.clipRect`（页面坐标系矩形） |
| 顶边 margin | 节点起点在本页起点时四边归零 | 续页跳过 `spaceBefore`，末次切片跳过 `spaceAfter` |
| 命中 | 由 Composable 命中测试 + CFI | `PageContent.hitTest` 行级命中，限制在本页可见行 |
| 边框/背景 | 有 border/padding 模型 | 尚未实现（P3），测试用切片矩形模拟边框绘制 |
