## 2. 实现

- CSS 层（`computed_style.dart`）：
  - 新增 `CssLength`（value + `isAuto`/`isPercent` + `resolve(base)`）与 `CssBoxSizing{contentBox,borderBox}`；
  - `ComputedStyle` 新增不继承字段：`width/height/minWidth/maxWidth/minHeight/maxHeight`、`padding`（初始零）、`boxSizing`（初始 content-box）；
  - 尺寸支持 px/pt/pc/in/cm/mm/em/rem 换算，百分比保留标记交给盒模型解算，`auto` → `CssLength.auto()`，`none`（max-*）→ null；
  - `padding` 支持 1–4 值简写 + 四边长写覆盖，百分比按 `containingWidth` 解算，负值钳 0。
- 盒模型计算（新 `lib/layout/box_model.dart`）：
  - `BoxModel.fromStyle(style, containingWidth:)` 聚合 padding/border/margin/box-sizing/min-max；
  - `resolveContentWidth`：auto 宽 = 可用宽 − inset − margin；声明宽按 box-sizing 折算；min/max 钳制且 min 优先（CSS 2.1 §10.4）；
  - `resolveContentHeight`：未声明用实测内容高；`borderBoxWidth/Height` 由内容盒加回 inset。
- 块测量（`block_flow.dart`）：
  - `TextFlowBlock` 用盒模型内容宽断行，尺寸 = 边框盒（内容 + padding + border），暴露 `boxModel`；
  - `ColumnFlowBlock.styled` 让容器 padding/border 压缩子块可用宽并计入自身尺寸（既有位置参数构造保留）；
  - `createFlowBox` 容器分支改走 `styled`；margin 折叠、首元素负 margin 钳制、脱离流语义不变。
- 绘制（`page_renderer.dart`）：
  - 文本 x 偏移 `border.left + padding.left`，块首切片整体下移 `border.top + padding.top`（P2-13 的「边框压住首字符」随之修复）；
  - 背景/边框仍铺满边框盒，圆角/虚线逻辑不变，切片裁剪矩形同步延长 top inset。

## 3. 与阅微的对照

阅微（反编译 `BoxConstraints` / `ContainerDom`）：

- `BoxConstraints.compute(ContainerDom)`：先按 `boundaryWidth`（border+padding+margin 水平）扣减内容宽，再裁掉浮动占用，`width` 固定时覆盖内容宽；`prepare(dom)` 对浮动做 `min(内容宽, max-width)` 收缩；表格有单独 `compute(TableDom)`。
- `calculateSize`：`heightGuaranteed = 内容高 + margin.getHeightGuaranteed()`；`box-sizing: content-box` 时把 border+padding 加回尺寸；`size.width = border + content + padding + margin + direction + viewport`；固定 `width/height` 覆盖实测值。
- 负 margin / 首元素负 margin 钳制在 `ContainerDom.onLayout`（P2-08/P2-09 已对齐）。

我们的实现：

| 维度 | 阅微 | 我们 |
|---|---|---|
| 边界合成 | `boundaryWidth = border+padding+margin` 一次算出 | `BoxModel.horizontalInset`（padding+border）+ 既有 margin 折叠 |
| box-sizing | content-box 加回 border+padding | `BorderBox` 先扣 inset，`contentBox` 直用（相同语义） |
| 尺寸来源 | 固定宽覆盖实测，浮动/表格分派 | `resolveContentWidth/Height`：声明值优先、auto 用可用宽、min/max 钳制 |
| 百分比 | CSSUnit 解算 | `CssLength.resolve(containingWidth)`；height 百分比按 containingWidth 近似（注释说明） |
| 接入位置 | `compute` 在测量前算约束 | 两阶段测量内：`TextFlowBlock.onLayout` 求内容宽、`calculateSize` 合边框盒 |

## 6. 已知限制（含 Team 上报）

- `TextFlowBlock` auto 宽沿用「块宽 = 实测最长行宽」的收缩语义，不是 CSS 块级的「填满包含块」；改成填满会破坏既有 11 组块测试的期望值，留给分页/行宽统一时再对齐。
- 空文本块仍返回 `Size.zero`（padding 不把空块撑开）。
- `ColumnFlowBlock` 子块的可用高未扣 `verticalInset`，页高很紧时靠最终约束钳制兜底。
- 分页/命中几何未接 inset：`Paginator.usedHeight`、`PageContent.hitTest` 仍按纯行高推进，而绘制层把块首 top inset 计入 y，同一页多个带 inset 的块会有坐标偏移；需要分页层统一（下一批分页任务）。
- `padding` 不支持 `calc()`/`var()`；百分比 height 按 containingWidth 近似；`createFlowBox/TextFlowBlock` 暂无生产调用点（骨架期）。
