# P3-13 测试报告：实现 createPlaceholders（容器绕排分支）

任务：按当前 y 生成占位节点并返回收窄后的约束，接入块流（P3 任务书 ｜ 预算 4h）

## 交付

- `packages/reader_core/lib/layout/block_flow.dart`
  - `FloatFlowBlock` 携带样式（float 方向 + margin 来源），`side` 派生 left/right；`createFlowBox` 传样式
  - `ColumnFlowBlock.onLayout` 浮动分支：fit-content 测量后按当前位置（cursor + margin.top）登记进容器 `FloatOccupancy`（左浮贴左缘、右浮贴右缘，含 margin）；不推进块流、不进顶位表（childTops 语义不变）、不参与 margin 折叠
  - 流内块绕排收窄：首趟全宽测量 → 按块高度区间查 `contentWidthAt` → 收窄了才重测（≤3 趟收敛）；`childLefts` 记录左缩进（左浮占位后文本左缘 = 浮动右缘）
  - `ColumnFlowBlock.floats` / `childLefts` 暴露给跨页衔接（P3-15）与绘制
- 测试：`test/layout/float_test.dart`（4 用例：左浮收窄不越界、右浮右扣、浮动结束后恢复全宽、无浮动树单次测量不变量）；存量 288 布局用例全过

## 验收对照

| 验收项 | 结果 |
|---|---|
| 图文绕排样本文字不重叠 | ✅ 左浮样本：文本块 childLeft == 浮动右缘（浮动的水平区间不与文字重叠） |
| 不越过浮动边界 | ✅ 文本块宽度 ≤ 绕排区间可用宽（contentWidthAt），右浮样本可用宽 = 容器 - 浮动宽 |

## 关键实现决策

1. **容器级块粒度收窄**（而非阅微的行级占位节点）：本引擎 TextLayout 按整段固定宽测量，行级绕排需要文本引擎逐行接入左右内缩（P5 竖排重做时一并评估）；块粒度已满足「不重叠、不越界」验收，浮动下方恢复全宽。
2. **单次测量不变量的边界**：无浮动树严格单次测量（不变量用例保留）；有浮动树允许 ≤3 趟有界重测且结果确定性（occupancy 清空重建幂等）——混合样本用例口径从 `<=1` 放宽到 `<=3` 并注明原因，防震荡的初衷不变（宽度单调收窄、不摆动）。
3. **浮动不进顶位表**：childTops/childLefts 只覆盖流内子块（block_invariant 不变量保持）；浮动位置由 `floats` 占用矩形承载，绘制路径（P3-15/P3-16）从占用取几何。
