# 全书回归 R10（1541 章）

> 数据：`test_corpus/real/zhushen-yuxi.epub`，390×873 内容区，阅读器默认 overrides。
> 目的：确认 CSS 对齐九轮改动（竖排、绝对定位、行内盒、浮动、多列、孤行寡行、
> 生成内容、z-index、百分比圆角、3D 边框）累积后，全书分页无回退。

## 结果

| 指标 | R5 基线（f5b3389 时期） | R10（本机实测） | 判定 |
| --- | --- | --- | --- |
| 章节数 | 1541 | 1541 | 一致 |
| 总页数 | 11640 | **11774**（+134，+1.15%） | 预期内：`orphans/widows` 把行推到下一页 |
| 空页 | 7 | **7** | 一致 |
| 负块高 / NaN 切片 | 0 | **0** | 一致 |
| 行内浮动块 | 82（5 + 63 + 14） | **82** | 逐项一致（spine28 5 / spine29 63 / spine4 14） |
| 单章耗时 | 73ms（p95 115ms） | 402ms/章（1541 章 619s） | 见说明 |

**说明（耗时）**：本轮 sweep 用 `flutter test` 逐章 `loadChapter` 且未复用页缓存，
402ms/章是「冷启动 + 测试环境」口径，不能与 T8 的批量扫描（73ms/章）直接比较；
耗时回归需要 T8 的 sweep 脚本在同参数下复跑才有可比性。

## 结论

- 页数增量全部可由「孤行寡行约束」解释（每章平均 +0.09 页）：把页尾孤行推走必然
  增加页数，属预期行为而非排版错误。
- 空页数量、NaN/负高、浮动块数量与基线逐项一致，九轮改动未引入结构性问题。
