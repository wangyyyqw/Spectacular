## 1. 实现

- CSS 层新增模型：`CssBorderStyle`（none/solid/dashed/dotted/double）、`CssBorderSide`（宽/线型/色）、`CssBorders`（四边 + 四角圆角，`hasBorder`/`hasRadius`/`isUniform`）。
- `ComputedStyle` 新增三个不继承字段：
  - `backgroundColor`：`background-color`，初始透明；
  - `backgroundImage`：`background-image: url(...)` 的 URL（渐变与 `none` 归 null），绘制留资源任务；
  - `borders`：`border` 简写、`border-width/style/color`（1–4 值按 CSS 展开）、`border-top/right/bottom/left` 简写与 `border-*-width/style/color` 长写；只写线型不写宽度按 `medium=3px`；`border-radius` 1–4 值（忽略 `/` 后的椭圆半径）与四角长写。
- 绘制层（`PagePainter`）：
  - 每个切片先画背景 `RRect`：跨页切片只在块真正开始/结束时带上下圆角；
  - 再画边框：四边一致且实线 → 整框 `RRect` 描边（圆角生效）；否则分边绘制，`solid` 直线、`dashed` 3w 段/2w 隙、`dotted` w 段/3w 隙圆头、`double` 双细线；
  - 背景与边框都在 P2-10 的切片裁剪矩形内，跨页不越界。

## 2. 与阅微的对照

阅微的做法（反编译 `BorderInfo` / `CSSBorderNode`）：

- `BorderInfo`：四边各存 `(color, style, width)` + 四角 `CornerRadius` + border-image 的 source/slice/width/repeat。
- `CSSBorderNode.draw`：有圆角走 `drawRoundedBorders`（均匀时一条整框路径，四边不同时逐边路径 + 三角形斜接 `drawTriangleBorders`），无圆角走 `drawStraightBorders`（每边一条 `drawRect` 描边）；`double` 用 `drawDoubleRectangleBorders`。
- 虚线：`createOptimizedDashEffect` 按 `pathLength` 调整 dash；直边绘制时虚线 `dashPathEffect([w*3, w*2])`（butt cap），点线 `[w, w*3]`（round cap）。
- 背景色/图由背景节点单独绘制，与边框分离。

我们采纳与不同的部分：

| 维度 | 阅微 | 我们 |
|---|---|---|
| 模型 | `BorderInfo`（含 border-image） | `CssBorders`（四边 + 圆角，无 border-image） |
| 圆角 | 均匀/非均匀都有圆角路径与斜接 | 只有四边一致实线走圆角整框；其余分边直线（不做斜接） |
| 虚线 | 按路径长度优化 dash，可沿圆角路径 | 直边手工切段，圆角不参与虚线 |
| 双线 | 两条矩形描边 | 两条平行细线 |
| 背景 | 独立背景节点 | 切片内先画背景 `RRect` |

## 5. 已知限制

- 还没有 padding/border 盒模型：边框画在块边界上、不为内容内缩（文字从 x=0 起时左边框会压住首字符，样本用 `text-indent` 规避）；P2-14 盒模型接入后内容会按 border 内缩。
- 相邻边宽度不同时没有 45° 斜接（阅微有 `drawTriangleBorders`），四条边按平头线段各自绘制。
- `border-image` 未实现；`background-image` 只解析 URL，不下载/绘制（资源任务）。
- 虚线/点线不沿圆角路径；`double` 是两条平行细线的简化实现。
- 竖排/RTL 未接入。
