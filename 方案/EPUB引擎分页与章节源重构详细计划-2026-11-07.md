## 三、工作包 F：分页规则

### 3.1 规范与产品决策

以 CSS Fragmentation Level 3 的 §3.3、§3.4、§4.3、§4.4 为依据：

- `orphans` 是断点前片段的最少行盒数；
- `widows` 是断点后片段的最少行盒数；
- 两者初始值为 2，可继承，只接受正整数；
- 0、负数、小数和带长度单位的值应忽略，不能静默钳成 1。

若整段少于任一约束，优先整段保持；仍须保证超高内容能推进。CSS 不要求唯一最优断点，本计划采用“在合法候选中尽量填满”的可解释策略，不声称全局最优。

`pagination_break_test.dart:68–80` 固定了“不做孤行/寡行、4 行容量 3 时切 3+1”的旧决策。启用 2/2 是有意的行为变更；需要保留旧贪心测试时，应显式设置 1/1，而不是批量覆盖 golden。

### 3.2 样式模型与别名归一

建议的语义对象为 `FragmentationStyle`，包含 `before`、`after`、`inside`、`orphans`、`widows`。是否独立建类由实现评审决定，但不能让布尔字段和对象各持一份可变真相。

当前读取顺序已核验为四处不一致：

```dart
// computed_style.dart:2536–2548
pageBreakBefore  = page-break-before ?? break-before
pageBreakAfter   = page-break-after  ?? break-after
rawBreakInside   = break-inside      ?? page-break-inside
breakAfterAvoid  = break-after       ?? page-break-after
```

实施要求：

1. 在 `ComputedStyle` 的初始值、`computedValue`、校验、构造、继承与复制链完整接入两个整数；把 `orphans`、`widows` 加入 `Cascade.inheritedProperties`。
2. 在 `Cascade._considerDeclaration`/`_expandShorthand` 的既有展开链上，把 `page-break-before/after/inside` 映射到 `break-before/after/inside` 的同一竞争槽位。`always` 映射为 `page`；不能固定“新名优先”或“旧名优先”。
3. 原始声明可为诊断保留；旧测试若检查 `values` 中的旧名，应区分“原始声明展示”与“计算值规范名”，逐项迁移，不制造双真相。
4. 支持 `auto`、当前分页需要的 `page`/`always`、`avoid`/`avoid-page`。`left`/`right` 当前只作为强制分页，不代表奇偶页能力；是否补 `recto`/`verso` 不在本轮默认范围。
5. 直接构造 `ComputedStyle` 的入口（如 `UaBlockDefaults.apply`、`_firstLetterRun`、测试辅助构造）也要调用同一规范化函数。`property_aliases.dart` 的集中映射可作为形式参考，但标准旧名不要混入厂商私有属性表。
6. `var()`、`inherit`、`initial`、`unset`、`!important` 的处理必须与现行级联一致，不借机扩展没有基础的其他 CSS-wide 关键字。
7. `orphans`/`widows` 不参与字形测量，不放进文本测量缓存指纹；它们与 break 值属于分页决策依赖，应进入块/分页依赖。

### 3.3 普通横排候选算法

先对稳定行布局实现纯候选选择器。输入至少包括：

- 逻辑段落标识；
- 总行区间；
- 当前片段起点；
- 当前页/空白页几何；
- 容差；
- `orphans`/`widows` 约束；
- 已有断页限制。

输出为结束行、下一步动作和降级原因。选择器不写缓存、不移动 CFI、不进行绘制。

对于段内候选 `k`，必须区分三种行数要求：

1. 首次片段若未结束，至少满足 `orphans`；
2. 中间片段同时承担上一断点的 `widows` 和下一断点的 `orphans`；
3. 最终续片段至少满足 `widows`。

整段能放完时，不强造分片。基础筛选为：

- 本片段实际行数满足对应下限；
- 若 `k` 未到段落结尾，剩余内容至少能形成合法的下一片段；
- 候选满足高度、容器续框、段前后、trim 和容差；
- 在合法候选中选最靠后的一处。

不能只检查“剩余文本总共至少两行”，还要验证下一空白页能容纳该最小片段。

工程要求：

- 回退结束行后重新计算片段高度、trailing、最后一行 trim、容器底边和 padding，不能只改行号。
- 首字下沉、行内浮动或列布局拆出的多个 `PageBlock` 要有可追溯的逻辑段落身份与行范围，不能把每个物理块当成新段落重新计数。
- 使用有界前瞻和页内未提交切片调整，不回溯整章已提交页面；复杂度目标为行数近线性。
- 每轮必须推进逻辑内容游标、产生非空片段或退出；达到上限立即停止内层循环。

### 3.4 强制、avoid 与降级顺序

先执行取消、页数/工作量上限和非法几何防线。正常断页时：

1. 强制 `before`/`after` 覆盖避免断页约束；
2. 同一边界不能重复 `record` 制造空页；
3. 在剩余合法候选中同时考虑组关系、`inside`/`after avoid` 和行数约束。

无合法候选时，先判断移到下一空白页是否能解决，只能有界移动。仍不足时，依据规范先放宽行数限制，再放宽 avoid 类限制，最后在超高原子内容上采用现有强制推进/裁剪策略。不得把“永远先牺牲 `widows` 再牺牲 `orphans`”写成规范结论。

同一降级层内的选择属于引擎策略：尽量不丢内容、少产生空白、保证终止，并记录本段何种约束物理不可满足。物理上不足一行的页高、超大正整数约束、超高单行和续框装饰必须有确定性终止用例。

### 3.5 标题与补丁简化

标题默认规则由 UA 提供；作者明确的 `break-after: auto/page` 及重要性必须有效。章节源的结构化标题启发式只用于没有可用作者断页意图的兼容场景，应显式标识为阅读器策略，不能在构块后无条件覆盖作者计算值。

现有 avoid 只预留下一块首行。引入 2/2 后，应改为下一块的“最小合法起始片段”；否则标题可能留在本页、正文因孤行约束整体后移，标题再次孤立。连续章号/章名、空块、`display:none`、零高块要做有界链扫描；遇 force 即截断，组合高于整页时降级而不是死循环。

补丁分三类：

| 类别 | 处理 |
|---|---|
| 可合并 | 标准 `h1`–`h6` 的 UA 默认与重复 avoid 标记；必须覆盖全部等价测试且不破坏作者覆盖 |
| 条件保留 | 无语义标题标签、容器首子块等启发式；汇入统一 `HeadingPolicy` 并记录来源，实测后决定精简 |
| 不替代 | figure 图题组、浮动容器组、表头重复、fixed 覆盖、超高内容兜底；它们不是 `orphans`/`widows` 的同义机制 |

### 3.6 分页路径接线范围

| 路径 | 当前特点 | 计划要求 |
|---|---|---|
| 同步普通横排 | 按行贪心，已有 group 和 avoid | 最先接入统一候选策略，建立精确几何回归 |
| 移动端浮动 | 独立状态机；绕排重测、`charCursor` 推进 | 按真实剩余宽度重测后计行，使用同一约束语义 |
| 流式分页 | 独立贪心、`CancelToken`；与同步功能不等价 | 先盘点真实调用方；统一决策或明确能力限制 |
| 表格 | 按行边界切，续页表头另处理 | 不把表格占位行套文本行数；单元格正文单独测试 |
| 多列 | 列分配与 `column-fill` 控制 | 区分分页上下文和列上下文，保留列语义 |
| 竖排 | 行模型为列，按页宽推进 | 用逻辑轴语义评审，不能把列数误当横排行数 |
| 全屏图/固定版 | 无段落行盒 | 两个属性不适用；强制断页和快路降级仍须保持 |
| 连续滚动 | 消费章节分页派生几何 | 验证页边界改变不造成额外空隙、跳位或进度反写 |

F 第一里程碑可以只验收普通横排，但 F 总包完成必须有每条路径的支持/不适用/限制结论及对应测试。

### 3.7 页索引与缓存

当前 `PageIndex.currentSchemaVersion` 为 5（`page_index.dart:68`）：

- 解码在 `135–172` 拒绝非 5 版本；
- 重放在 `179–292` 校验页高与 `usedHeight`，`277` 处容差为 0.01。

旧索引记录的 3+1 边界可能几何完全正确，新规则不会使其 `usedHeight` 校验失败。启用新决策时，应提升到下一可用版本，并在分页 key 增加明确的 fragmentation revision 或等价失效机制。

纯 UA 注释整理和 R 纯结构重构不提升索引版本。分页算法、UA 语义或可配置默认值确实变化时才升级，并记录原因。行数属性不进入颜色/主题键；重排后位置仍以 CFI 恢复，页码允许改变。

## 四、工作包 U：UA 样式治理

### 4.1 保留既有结构

当前 `uaStylesheetCss` 与 `UaBlockDefaults` 并存：

- `uaRules()` 是完整规则集，供 `Cascade.compute` 使用；
- `UaBlockDefaults` 是部分旧块级覆盖层，只含当前排版/绘制栈已消费的物理属性。

不能在没有调用方清单时直接删除 `UaBlockDefaults`，也不能要求两条入口对所有标签输出相同声明。

每项规则或不可再拆的规则组应记录：

- 稳定 ID；
- 规范名称与锚点；
- 默认值理由；
- 项目差异；
- 实现消费者；
- 支持状态；
- 测试 ID；
- 原始顺序号。

例如 `UA-HTML-1536-H1` 应说明字号/段距来自 HTML 建议、避页底是阅读器增强、作者仍可覆盖。

章节号只作辅助定位，必须同时保存稳定章节标题或 URL 锚点。WHATWG 是可更新文档，不能只写数字让未来维护者猜版本。

### 4.3 保序原则

CSS 源顺序参与层叠。按规范编号搬动规则不天然行为不变，`pre`、`body`、列表和属性选择器可能重叠。

- 第一轮只补注释和台账，保持选择器、声明、`!important` 和输出顺序不变。
- 后续分文件/常量分组时，逻辑分组与发射顺序分离：规则保留原始 ordinal，最终拼接按已审计顺序。
- 对确有必要重排且能证明交换无影响的规则，逐项记录冲突分析并通过 computed-style 差分。

### 4.4 双入口与支持状态

每个规则标记为：

- 仅保存声明；
- 已参与计算样式；
- 已影响布局/绘制；
- 兼容近似；
- 暂不支持。

不要把字符串出现当成可见行为。对 `UaBlockDefaults` 只验证其承诺子集：标题、引用、列表、表头、`hr` 等与完整路径的计算效果；有意差异写明理由。

旧测试只断言规则数 ≥30，不能防止关键规则被等量替换。新增稳定 ID 唯一性、来源字段、重要规则存在、作者覆盖、二入口子集与源顺序语义测试。

### 4.5 注释模板

每项至少说明：

1. 规则 ID；
2. 依据及章节锚点；
3. 选择该默认值的理由；
4. 与规范/浏览器的差异；
5. 作者覆盖边界；
6. 实现消费者；
7. 回归用例；
8. 状态与遗留项。

### 5.8 缓存、字体与生命周期

不在纯搬迁时顺便统一所有缓存策略。`BoundedCache` 不负责淘汰回调或资源 dispose；当前页淘汰与页索引联动、块缓存独立淘汰，这些语义需先固化。

字体加载后必须重新验证会话 generation。布局 generation 与字体 revision 不是同一维度；不能每注册一次字体就让触发注册的作业自行过期。建议等待结束后获取稳定字体视图，提交时再验证本作业实际引用的字体族是否变化。

需要补验收的风险：

- 页缓存已清但块/索引仍在时，字体定向失效是否遗漏；
- 未知字体依赖是否保守失效；
- 快路是否提前写缓存；
- 索引重放是否重复/遗漏 fixed 覆盖。

`close` 验收是归档只关一次、Dart 字节/映射释放、晚到异步回调不复活缓存、重复 close 安全。Flutter 字体引擎不能据此承诺同步卸载全部原生字体。

### 5.9 CFI 与文本变换不变量

源码实际使用 CFI 与 UTF-16 坐标，不能把源码 `sourceSpan`、聚合纯文本索引、显示文本偏移和 CFI 字符偏移混为一个值。

坐标模块需区分：

- XHTML 源码位置；
- 聚合原文；
- pseudo/quote 插入后位置；
- 首字或浮动摘除后位置；
- 分页子串位置。

删除并非天然可逆，生成内容也未必有原文位置；必须明确前/后边界吸附策略，而不是承诺双射。阅读位置比例必须使用 `TextLengthScanner` 的正文语义计数，不能混用原始 XHTML 去标签长度、聚合索引或像素偏移。

纯重构验收时，每页首末 CFI、命中字符、选区、脚注和装饰锚点必须等价；新增分页功能只允许改变页边界，不允许改变 CFI 指向的正文内容。

## 八、性能、内存与真机验收

在 G03 记录同机同包模式、固定字体/样本的：

- 冷打开；
- 首次长章布局；
- 缓存回访；
- 索引重放；
- 翻页；
- 字号重排；
- 内存峰值；
- 关闭后保留量。

纯重构与功能版分别对比，不能因新页数不同直接比较总时间而误判。

每个场景至少多次采样，报告中位数、尾部值与样本数。建议将中位数回退 5% 或尾部回退 10% 视为调查线，而非统计学上的自动失败结论。比较每千行决策成本与内存增量，防止候选回退引入平方复杂度。

真机选择隔离测试库/包，覆盖短书、长章、图片、表格、脚注、浮动、竖排和多列，反复字号/尺寸往返并切换分页/滚动。记录设备、系统、SDK、包 hash、样本 hash、操作与截图/日志；不得清理用户原书或标注来换取“干净环境”。

## 九、风险与回滚

| 风险 | 应对与回滚边界 |
|---|---|
| 工作树并行变更 | 实施前重取基线；一文件一写入者；不 reset、覆盖或替人提交已有改动 |
| CSS 别名归一改变旧覆盖 | 值模型/UA 语义独立提交；旧/新名竞争矩阵先行；保留诊断来源 |
| 默认 2/2 改变页数 | 单独功能基线、页索引换代、CFI 恢复；回滚代码时旧缓存也按版本废弃 |
| UA 重排改变同特异性胜出 | 第一轮保序；必要交换逐条计算样式差分，不批量更新快照 |
| 图题/浮动组误删 | group 与行数分开建模；无替代等价证据不得删除 |
| 闭包改字段引入跨作业污染 | Scratch 每次新建；不把可变状态提升为全书共享；可控并发测试 |
| 坐标变换损坏标注 | UTF-16/CFI 独立性质测试；出现正文错位立即回滚该职责提交 |
| 阅读位置契约迁移 | 保持 0–1 比例、CFI 双向换算与正文语义字符数；多章不等长/单章/缺章样本对照 |
| 字体晚到覆盖新布局 | job 与字体依赖双重校验；清页留块/索引必须覆盖 |
| 双路径长期存在 | 过渡期短且有退出任务；不正式双跑资源副作用；R7 删除旧实现 |
| 极端约束死循环 | 非空推进不变量、有限前瞻、小上限压力测试；未通过不合并 |
| 测试基础环境失败 | G02 阻塞；如实区分加载失败、编译失败与断言失败，不猜根因 |
| 参考材料版权/证据偏差 | 只采用公开标准和高层规格；不复制逆向实现；类名不当算法证明 |

每个可独立回退的任务对应一个或数个小提交，不用整仓 reset。纯重构阶段不做数据库或锚点格式迁移，保持代码回滚边界清晰。分页语义版本必须单调更新；代码回滚不能误用新旧决策混杂的页索引。
