## 一、范围与产品行为

性能修复、章节源职责拆分、UA 治理与分页路径统一合并实施。保留现有 CFI、书签、标注及原始阅读锚点，字节进度算法与锚点语义版本独立。

- 取消阅读路径的全书精确字数扫描，包括开书与比例计算中的隐式扫描。导入时已有字数字段不被字节权重污染。
- 忽略书内 `orphans`、`widows`，包括 `!important`。保持合法断点的尽量填满策略，保留强制断页、图题成组、表头及标题避页底。
- 正文、百分比、当前页／本章总页数一起提交；字号变化期间保留旧正文与对应家具。
- 同一 CFI 的全书百分比不随字号改变。实际全书页数独立后台累计，无缓存从 0 开始，未完成显示“已排 N 页”，完成显示“全书 N 页”。

上一版关于默认孤行／寡行 2/2、约束继承、候选回退器的实施任务已全部取消；不以更新 golden 方式掩盖旧贪心行为的回归。

## 三、进度、首屏与分页规则

### 3.1 轻量进度

从 ZIP 中央目录读取章节 XHTML 未压缩大小，旧归档后端只读条目 `size`。

```text
全书比例 =（此前章权重和 + 本章权重 × 本章原文位置比例）÷ 总权重
```

`BookProgressIndex` 保存不可变权重、前缀和、排除集合和算法版本；显示、跳转、保存、书架恢复共用。章内比例由聚合原文 CFI 偏移／长度提供，仅准备目标章。纯图片章使用可定位元素的文档顺序。目录、非正文、确认缺失章节沿用已有排除策略；大小元数据不可用时全书按可读章等权降级。

百分比跳转先用权重二分定位目标章，再异步准备该章坐标。删除 `ensureCharacterIndex` 生产入口、任务与 `_weightsForPosition` 全书兜底。旧百分比首次可校正一次，原始 CFI 与标注不迁移、不删除。

### 3.2 一次首屏排版

内容准备与封面动画同时启动。顺序固定为：恢复 CFI → 目标章结构 → 原文核验本章装饰与字体加载 → 冻结布局输入 → 完整排版 → 同次提交正文与两个进度数字。

`AnchorChapterSource` 提供原文，装饰核验不能调用 `loadChapter`。其他章的装饰随请求准备；纯颜色、标注与自动规则只重绘。滚动首屏只等当前章，邻章稍后补入。

### 3.3 统一断页语义

在级联竞争前把 `page-break-before/after/inside` 放入 `break-before/after/inside` 的同一槽位；`always` 归一为 `page`。特异性、来源、重要性、声明顺序、变量与 CSS-wide 关键字继续沿用现有层叠。直接构造 `ComputedStyle` 也走同一归一入口。

普通与流式分页消费同一候选算法；浮动消费同一类型字段。保留合法正文断点、强制 break、图题组、表头、容器续框、标题避页底、竖排与多列行为。

分页语义改变统一提升页索引版本；纯职责迁移不升级。只有结构化等价证据充分时才删除旧补丁和过渡实现。

## 四、工作包 U：UA 样式治理

### 4.1 保留既有结构

当前 `uaStylesheetCss` 与 `UaBlockDefaults` 并存：

- `uaRules()` 是完整规则集，供 `Cascade.compute` 使用；
- `UaBlockDefaults` 是部分旧块级覆盖层，只含当前排版/绘制栈已消费的物理属性。

不能在没有调用方清单时直接删除 `UaBlockDefaults`，也不能要求两条入口对所有标签输出相同声明。

每项规则或不可再拆的规则组应记录：

- 稳定 ID；
- 规范名称与锚点；
- 默认值理由；
- 项目差异；
- 实现消费者；
- 支持状态；
- 测试 ID；
- 原始顺序号。

例如 `UA-HTML-1536-H1` 应说明字号/段距来自 HTML 建议、避页底是阅读器增强、作者仍可覆盖。

### 4.2 逻辑分组

| 分组 | 内容与取舍 |
|---|---|
| HTML 15.3.1 | 隐藏元素、`hidden`、`noscript`、`dialog`；明确脚本禁用策略 |
| HTML 15.3.2 | `html`/`body`、页面默认边距；区分规范建议与阅读器接管 |
| HTML 15.3.3 | `p`、`blockquote`、`figure`、`pre` 及遗留表现属性 |
| HTML 15.3.4 | `strong`/`em`/`code`、上下标、装饰、`nobr` |
| HTML 15.3.5 | `bdi`/`bdo` 及 `unicode-bidi`；区分解析支持与实际布局支持 |
| HTML 15.3.6 | 分节/标题字号段距；断页增强另标项目来源 |
| HTML 15.3.7 | 列表、缩进、marker 与嵌套；记录 flat 近似 |
| HTML 15.3.8 | 表格、单元格、caption 与表头 |
| 其他 HTML/嵌入 | 表单最小集、`hr`、图片/媒体；保留不支持标签策略 |
| CSS Ruby | `rt`/`rtc` 默认；注明实现范围 |
| Reader policy | `flow-root`、`overflow`、正文区约束与私有契约，不伪装成规范强制 |

章节号只作辅助定位，必须同时保存稳定章节标题或 URL 锚点。WHATWG 是可更新文档，不能只写数字让未来维护者猜版本。

### 4.3 保序原则

CSS 源顺序参与层叠。按规范编号搬动规则不天然行为不变，`pre`、`body`、列表和属性选择器可能重叠。

- 第一轮只补注释和台账，保持选择器、声明、`!important` 和输出顺序不变。
- 后续分文件/常量分组时，逻辑分组与发射顺序分离：规则保留原始 ordinal，最终拼接按已审计顺序。
- 对确有必要重排且能证明交换无影响的规则，逐项记录冲突分析并通过 computed-style 差分。

### 4.4 双入口与支持状态

每个规则标记为：

- 仅保存声明；
- 已参与计算样式；
- 已影响布局/绘制；
- 兼容近似；
- 暂不支持。

不要把字符串出现当成可见行为。对 `UaBlockDefaults` 只验证其承诺子集：标题、引用、列表、表头、`hr` 等与完整路径的计算效果；有意差异写明理由。

旧测试只断言规则数 ≥30，不能防止关键规则被等量替换。新增稳定 ID 唯一性、来源字段、重要规则存在、作者覆盖、二入口子集与源顺序语义测试。

### 4.5 注释模板

每项至少说明：

1. 规则 ID；
2. 依据及章节锚点；
3. 选择该默认值的理由；
4. 与规范/浏览器的差异；
5. 作者覆盖边界；
6. 实现消费者；
7. 回归用例；
8. 状态与遗留项。

禁止只写“参考 Reeden”而无具体可核实来源，也不复制逆向实现代码。

## 五、工作包 R：章节源拆分

### 5.1 目标与红线

目标是降低变更波及范围、减少隐式状态和缩短测试依赖链。

参考警戒线：

- 门面约 500–800 行；
- 内部编排方法约 150–250 行；
- 一般文件约 300–800 行；
- 复杂表格/浮动模块超过 1000 行时必须有独立算法边界与拆分理由。

这些是评审警戒线，不是通过缩行、合并语句就能达成的指标。

禁止：

- `part`、`mixin` 和公开全部字段的假拆分；
- 新增万能 `Context` 让所有模块读取全部状态；
- 改变数据结构却无意改变遍历顺序、计数器作用域、CFI 坐标或缓存拥有者；
- 用 107 个空壳类或把原巨类整体搬进 Builder。

### 5.3 状态所有权

| 状态域 | 拟议所有者 | 生命周期与禁止事项 |
|---|---|---|
| 书籍资源 | `BookResources` 及字体/样式仓储 | 打开到 `close`；只有一个归档关闭者，不是全局单例 |
| 会话设置 | `SourceSessionState` | overrides、视口、文字覆盖、generation；builder 不随时读取 |
| 布局快照 | `LayoutSnapshot` | 不可变几何/策略输入；字体就绪后冻结度量视图 |
| 单次作业 | `ChapterLayoutJob` | spine、快照、key、取消/过期检测、trace；结果只提交一次 |
| 构建临时状态 | `BuildScratch` 及各专用状态 | blocks、counter、quotes、容器、局部样式映射；构建结束释放 |
| 派生缓存 | `ChapterCacheStore` 及专属仓储 | key 与容量明确；存活于书实例不表示输入不变 |
| 阅读位置 | `ChapterPositionIndex` | `BookProgressIndex` 与单章原文坐标缓存；统一章内原文偏移与长度 |

### 5.5 依赖方向与编排

```text
门面
  → 会话/作业协调
  → 结构准备与 CSS/字体就绪
  → 快照冻结
  → 构块
  → 分页
  → generation 与字体依赖复验
  → 统一缓存提交
```

- builder 依赖样式、行内、图片、表格、容器等窄端口；
- table 可依赖 inline 测量，inline 不可反向依赖 table；
- 任何内部模块不得 import `EpubChapterSource` 或持有它；
- `reader_core` 继续拥有 `Cascade`、`Paginator` 和 `TableGridMeasurer` 算法，不在 app 复制第二套。

特殊页面快路也返回“产物候选”，避免在分析函数内先写页索引、之后才检查作业过期。取消/缺章/失败应是内部明确状态，由门面映射回现有公开契约，不用同一个空列表隐含四种含义。

### 5.6 先消除的闭包与时间耦合

1. `styleForChain` 同时返回样式并修改 `containerBorderedForLastChain`、`promotedLeftForLastChain`、`effectiveOpacityForLastChain`。先改为显式返回 record。
2. `extractInlineFloat` 内部 `layoutContent` 捕获可变 `contentWidthLimit`。改为 `layoutContent(width)` 等显式入参，保留原测量顺序。
3. quote 与 remap 不能继续以捕获列表的匿名函数跨模块传递。建立带插入/删除顺序及边界偏置的值描述。
4. `rawDeclarations`、pseudo 胜出、`chainStyle` 当前语义可能不同。搬迁时先保持差异，统一算法另立修复任务。
5. counter、quotes、列表编号与 `figureSeq` 必须由同一个文档序遍历控制，不能并行按节点类型分组处理。

### 5.7 公共 API 与 Dart 可见性

Dart 的下划线是 library-private；普通 import 不能共享私有类。跨模块必要契约可采用无下划线类型，放内部目录并限制 exports；目录本身不是语言级访问控制。不要用 `part` 绕过边界，不公开全部内部 map。

门面必须保持：

- `open`/`openFile` 默认值；
- `document`、base 尺寸/style、trim、overrides；
- `anchorChapter`、`chapterPlainText`；
- `fullBleedAnalysis`、`chapterPageFlags`；
- `cacheReport`、命中计数、`invalidationLog`；
- 测试钩子、`close`/`isClosed`；
- `layoutDependency`、`layoutDependencyForSpine`；
- `bindProgressWeights`、`semanticCharacterCount`、`isChapterMissing`；
- `readingPercentForCfi`、`cfiForReadingPercent`、`cfiForTocEntry`；
- `toc` 对缺失章节的补全行为。

`OpfPageFlags` 若移动，应从原入口定向 export。逐个核对 `withLayoutWidth` 及手工重建块保留 `writingMode`、`isRtl`、`plainTextLayout`、`group` 和断页属性。

### 5.8 缓存、字体与生命周期

不在纯搬迁时顺便统一所有缓存策略。`BoundedCache` 不负责淘汰回调或资源 dispose；当前页淘汰与页索引联动、块缓存独立淘汰，这些语义需先固化。

字体加载后必须重新验证会话 generation。布局 generation 与字体 revision 不是同一维度；不能每注册一次字体就让触发注册的作业自行过期。建议等待结束后获取稳定字体视图，提交时再验证本作业实际引用的字体族是否变化。

需要补验收的风险：

- 页缓存已清但块/索引仍在时，字体定向失效是否遗漏；
- 未知字体依赖是否保守失效；
- 快路是否提前写缓存；
- 索引重放是否重复/遗漏 fixed 覆盖。

`close` 验收是归档只关一次、Dart 字节/映射释放、晚到异步回调不复活缓存、重复 close 安全。Flutter 字体引擎不能据此承诺同步卸载全部原生字体。

### 5.9 CFI 与文本变换不变量

源码实际使用 CFI 与 UTF-16 坐标，不能把源码 `sourceSpan`、聚合纯文本索引、显示文本偏移和 CFI 字符偏移混为一个值。

坐标模块需区分：

- XHTML 源码位置；
- 聚合原文；
- pseudo/quote 插入后位置；
- 首字或浮动摘除后位置；
- 分页子串位置。

删除并非天然可逆，生成内容也未必有原文位置；必须明确前/后边界吸附策略，而不是承诺双射。阅读位置比例必须使用 `TextLengthScanner` 的正文语义计数，不能混用原始 XHTML 去标签长度、聚合索引或像素偏移。

纯重构验收时，每页首末 CFI、命中字符、选区、脚注和装饰锚点必须等价；新增分页功能只允许改变页边界，不允许改变 CFI 指向的正文内容。

## 六、作业、缓存与全书计页

### 6.1 不可变作业与调度

每个 `ChapterLayoutJob` 持有不可变 `LayoutSnapshot`、自己的构块状态与取消令牌。完整布局键至少包含内容版本、章、几何与正文上内缩、排版设置、实际字体依赖、该章装饰度量、排版与间距版本。

`ScheduledChapterSource.scheduleChapter` 返回独立可取消句柄；同章同布局键共享在途计算，取消一个等待者不取消其他有效等待者。新的设置、旋转、定位与关闭使旧任务立即失效，提交前再次验证请求与字体依赖。

优先级为当前阅读／字号 > 邻页预取 > 全书计页。遍历、逐行测量、表格和分页均检查预算及取消：前台目标 4ms 一片，后台每帧最多 2ms。Flutter 文字测量仍在主 isolate，适合移出的纯数据工作才使用普通 isolate。

### 6.2 度量与缓存

标点候选行避免重复测量；只有可证明首尾／跨行调整不影响的行才复用基线。混合字体、ruby、禁则、坐标与留白结果不能近似替换。

字号改变按完整键选择结果，不再全清；主题颜色继续只重绘。近期完整结果最多 3 项，估算总容量 32MiB，优先当前章和上一字号。大于预算的条目不进入跨会话缓存。缓存不持有归档句柄，内容、字体、装饰、尺寸或排版版本变化不能命中旧结果；内存压力清理非当前项，关闭取消任务并释放资源。

### 6.3 独立页数状态

`BookPageCountState` 提供布局键、完成页数、完成章节数、章节总数、状态与失败章。首屏提交后启动；当前章结果直接计入。全书逐章使用同一作业、同一布局输入，完成一章只保留章页数与完成状态，不常驻全书页面。

每章完成累计，界面通知最多每 250ms 一次。退出或退后台暂停，重新进入可续算。失败章保持未完成，下次打开重试；部分结果不能标成完整，也不能作为阅读百分比分母。

复用 settings 按书籍内容版本与完整布局指纹存储，每本书最近两套配置。字号变化切换缓存，无有效缓存从 0 重新累计。字体晚到、装饰变更与配置切换不得串用计数。

## 七、五阶段交付与验证

每阶段独立验证、中文提交并推送。提交只包括明确路径，不提交日志、私有样本、构建产物与临时文件。

### 7.1 必测行为

- 开书恢复 CFI、旧进度、缺章、图片章、书签、标注与滚动；只准备目标章。
- 连续字号、旋转、跳转、关闭与字体晚到时，只有最新请求提交。
- 字号往返同一 CFI 比例一致；正文和章页码、百分比同次提交。
- 完整页数等于相同配置的逐章串行总数；恢复、暂停、失败和配置切换不串值。
- 同步、异步、浮动、表格、固定版、竖排、多列的原文与几何差分。
- 作者 `orphans/widows:2` 及 `!important` 不能把 3+1 改为 2+2；强制 break 仍生效。
- UA 顺序及作者覆盖不变，旧／新 break 属性按层叠胜者统一竞争。

## 八、性能验收与未处理风险

同设备、同字体、同样本、同 Release 入口前后各 5 轮；分别记录首次开书、字号更新、缓存恢复、首屏完整可见与最长连续 UI 阻塞。性能采样不与其他测试并发。

| 指标 | 门槛 |
|---|---|
| 开书及字号更新中位数 | 较同模式基线降低至少 50% |
| 审计长章字号更新 | ≤1000ms |
| 缓存字号恢复 | ≤100ms |
| 最长连续 UI 阻塞 | ≤50ms |
| 近期完整缓存 | ≤3 项、估算总容量 ≤32MiB |

文件大小加权仍是估算进度；实际计页需要时间，其完成不得成为任何阅读操作的前置条件。异常压缩、超长单段、字体失败、纯图片位置和媒体条件变化必须有测试与可见降级证据。未达到的门槛记录实测结果并继续优化，不标注完成。
